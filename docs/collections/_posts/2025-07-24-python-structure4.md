### Python `list` vs 전통적 `Array` 비교

| 항목 | 파이썬 리스트 (`list`) | 전통적 배열 (C, Java 등) |
| --- | --- | --- |
| **데이터 타입** | 여러 타입 저장 가능 (이질적 데이터 허용) | 동일한 타입만 저장 가능 (동질적 타입) |
| **메모리 구조** | 각 요소의 **주소(참조)**만 저장함 → 실제 데이터는 **Heap**에 존재 | 메모리상 **연속적인 공간에 직접 값 저장** |
| **유연성** | 크기 변경 가능, 삽입/삭제 용이 | 고정 크기, 삽입/삭제 시 효율 떨어짐 |
| **접근 방법** | 인덱스로 O(1) 속도로 접근 가능 | 동일 (배열도 인덱스 기반 접근) |
| **타입 제약** | 없음: `[“홍길동”, 173, 65]` 가능 | 타입 명시 필요: `int[]`, `float[]` 등 |


**공통점**

1. 연속적인 메모리 공간을 사용
2. 내부적으로 C 배열처럼 구현되어 있음
3. 인덱스를 통한 접근 가능
4. 배열처럼 위치만 알면 빠르게 접근 가능 (O(1) 시간)

**차이점**

| 항목 | 파이썬 리스트 (list) | 일반 배열 |
| --- | --- | --- |
| 데이터 타입 |  이질적 (다양한 타입 가능) | 동질적 (같은 타입만 저장) |
| 메모리 구조 | 값의 주소를 배열에 저장, 실제 데이터는 Heap 영역에 존재 | 배열 자체에 실제 값이 저장됨 |
| 유연성 | 크기 변경, 삽입/삭제 가능 | 고정 크기, 삽입/삭제 비효율적 |
| 타입 제약 | 없음 ([“홍길동”, 173, 65] 가능) | 타입 제약 존재 (int[], float[] 등) |

파이썬 단일 리스트

```python
["홍길동", 173, 65]  # 문자, 정수, 정수 — 서로 다른 타입을 한 리스트에 저장
```

파이썬 이차원 리스트

```python
[
    ["홍길동", 173, 65],
    ["홍길동", 173, 65],
    ["홍길동", 173, 65]
]
# 리스트 안에 리스트를 넣어 구성된 구조
# 각 내부 리스트는 동일한 구조지만, 파이썬은 타입을 강제하지 않음
```

**핵심 개념 요약**

- 파이썬 리스트는 **배열처럼 생겼지만 본질적으로 배열과 다름**, **이질적인 데이터를 저장하고 조작할 수 있는 유연한 구조**
- 실제로는 객체의 **주소(참조 값)**를 저장하는 컨테이너로 작동
- 저장된 객체는 **Heap 메모리**에 존재 → 어떤 데이터든 담을 수 있음
- 배열의 원칙(동질적 타입, 고정 크기)은 파이썬 리스트에 **적용되지 않음**
