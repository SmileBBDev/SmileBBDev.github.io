### 지역변수와 전역변수

지역변수(함수 내부에서 선언 : stack에 저장) ⇒ 지역변수가 해제 된 후 해당 변수를 호출하면 에러 발생

전역변수 ⇒ 함수들이 데이터를 프로그램이 종료 될 때까지 참조할 수 있음.

### 메모리 영역

1. heap - 동적 메모리 할당 (c : malloc)(c++/java : new), (파이썬은 사용하지 않아도 동작)
2. stack
3. 전역변수 영역
- 전역변수 영역은 다시 **초기화된 데이터 영역(.data)**과 **초기화되지 않은 데이터 영역(.bss)**으로 나뉨 
- `.data` : 초기값이 있는 전역/정적 변수 저장  
- `.bss` : 초기값이 없는 전역/정적 변수 저장
- **상수 영역** : 문자열 상수나 리터럴은 별도의 **상수 영역**에 저장되며 읽기 전용으로 동작.

4. 코드 영역






## Function(함수)
### 1. lambda ⇒ 무명 함수 : 다시 호출하지 않는 함수일 때 사용

재귀 호출(tree, factorial) : 함수가 함수를 호출할 때 사용(본인이 자신을 호출하는 경우 주로 사용), 종료 조건이 필요(무한 루프가 발생하면 stack overflow 발생)

### 2. parameter(매개변수) : 4가지 종류

1. require : 반드시 매개변수 개수가 일치
2. default : overflow의 파라미터 개수 문제 해결
3. key parameter 
4. variable length(*, **)

**Python의 오버로딩 대체 개념**  
파이썬은 overLoading(오버로딩) 문제가 **가변 인자(*args, **kwargs)**와 **default parameter**로 해결 해결되어 있음
- 타입 : 데이터 타입을 지정하지 않음
- 개수 : default parameter로 해
- **키워드 인자(keyword arguments)**  
  - 호출 시 매개변수 이름을 지정해 가독성을 높임



### 3. y = ax + b

**수학에서** x = 정의어,  y = 치역

**통계학에서** x = 독립변수, y = 종속변수

**컴퓨터에서** x =  입력, y = 출력

이 이론이 딥러닝까지 적용

### 4. 함수 이해하기

함수를 이해하려면 문법적 요소와 기능적 요소를 이해해야 됨

**프로그램의 순서 :** 입력 ⇒ 처리 ⇒ 출력 (함수도 프로그램 순서와 동일)

**함수 사용방법**

일반화와 다양성을 확보하기 위해 함수에 이름을 주고,

매개변수를 함수 호출 시 **입력** 받은 후, 함수의 내부(body)에서 **처리**하고 

return해서 함수의 결과 값을 **출력**한다.

```python
--------------------------------------- 
# 함수 작성 방법 
def 함수이름(처리할 매개변수) : 
	처리부분 
	return 출력할 값 반환 

함수호출(인자) 

----------------------------------------- 
def factorial(n) : 
	sum = 1 
	for i in range(n, 1, -1) : 
		sum += i 
	return sum 

factorial(5) 
----------------------------------------- 

```

프로그램은 함수가 함수를 호출하는 형식

그리고 컴퓨터의 구조는 함수를 베이스로 동작하게 만들어져 있음

함수가 실행되고, 계산이 끝나고 나면 함수가 호출된 곳으로 돌아가 출력 진행

이때 stack 메모리에 실행되어지는 데이터를 넣고, **push→push→push→pop→pop→pop** 등의 형태로 메모리에 쌓이고 꺼낸다
(stack은 앞에서 배웠던 heap과 stack 메모리)

### 5. 함수 호출 방식
내가 갖고 있는 **데이터를 전달하는 방법 2가지**

- **Call by value** : 함수를 call하는데 값으로 호출하겠다.
- **Call by reference** : 함수를 호출하는데 데이터를 전달해서 호출하겠다.

**스코프(Scope)**
- 지역변수는 함수 블록 내에서만 유효
- 전역변수는 프로그램 전체에서 접근 가능
- 파이썬은 함수 내부에서 전역변수를 수정하려면 `global` 키워드 필요


### 6. 함수와 메모리
- **Stack Frame**  
  - 함수 호출 시마다 **스택 프레임**이 생성되어 매개변수, 지역변수, 반환 주소 등을 저장.  
  - 함수 종료 시 스택 프레임이 해제됨.  
- **재귀 함수와 Tail Recursion**  
  - 일부 언어(C, Python은 기본적으로 지원하지 않음)는 **tail recursion optimization**을 통해 스택 오버플로우를 방지.  

### 7. 프로그래밍 원칙
- **DRY (Don't Repeat Yourself)**  
  - 중복된 코드를 함수로 묶어 재사용성 확보.  
- **High Cohesion, Low Coupling**  
  - 함수는 응집도 높게, 모듈 간 결합도는 낮게 설계하는 것이 유지보수에 유리.  


### 8. 추가 예시 코드 (Python)
```python
# Call by Value vs Reference 예시
def modify_list(lst):
    lst.append(10)   # 원본 리스트에 영향
    return lst

def modify_number(num):
    num += 10        # 원본 숫자에는 영향 없음
    return num

nums = [1, 2, 3]
print(modify_list(nums))   # [1, 2, 3, 10]
print(nums)                # [1, 2, 3, 10]

x = 5
print(modify_number(x))    # 15
print(x)                   # 5
```

### 쉽게 생각하기!

**레고 블럭을 떠올리자**

조그마한 레고를 조립하다 보면 큰 레고(조형물)이 만들어진다.

이처럼 작은 함수들이 모여서 시스템이 만들어 지고, 보이지 않는 추상화 개념이 쌓이게 된다.

레고 블럭을 크게 만들면 변화가 힘들듯이
함수도 **단일 책임의 원칙**이 있다.


**단일 책임의 원칙 :** 
한 가지 문제를 해결하는 내용으로 하나의 함수를 만드는 것

하나의 문제를 가진 함수들을 모아 큰 함수로 사용 함

문제를 잘게 나누고 → 함수로 구현 → 레고 블록처럼 함수 조립 → 문제해결 + 시스템 생성
