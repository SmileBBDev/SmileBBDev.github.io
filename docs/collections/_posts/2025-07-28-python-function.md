**지역변수와 전역변수**

지역변수(함수 내부에서 선언 : stack에 저장) ⇒ 지역변수가 해제 된 후 해당 변수를 호출하면 에러 발생

전역변수 ⇒ 함수들이 데이터를 프로그램이 종료 될 때까지 참조할 수 있음.

**메모리 영역**

heap과 stack을 배웠는데 다른 영역도 존재

1. heap : 동적 메모리 할당
- c - malloc, c++/java - new, 파이썬은 사용하지 않아도 동작
1. stack
2. 전역변수 영역
3. 코드 영역

**lambda** ⇒ 무명 함수 : 다시 호출하지 않는 함수일 때 사용

재귀 호출(tree, factorial) : 함수가 함수를 호출할 때 사용, 종료 조건이 필요(무한 루프가 발생하면 stack overflow 발생), 본인이 자신을 호출하는 경우 주로 사용함. 

**parameter(매개변수)** : 4가지 종류

1. require : 반드시 매개변수 개수가 일치
2. default : overflow의 파라미터 개수 문제 해결
3. key parameter 
4. variable length(*, **)

파이썬은 over loading 문제가 기본적으로 해결되어 있음.

타입 : 데이터 타입을 지정하지 않음

개수 : default parameter로 해

**y = ax + b**

수학에서 x = 정의어,  y = 치역

통계학에서 x = 독립변수, y = 종속변수

컴퓨터에서 x =  입력, y = 출력

이 이론이 딥러닝까지 적용됨.

**함수 이해하기**

함수를 이해하려면 문법적 요소와 기능적 요소를 이해해야 됨.

프로그램의 순서 : 입력 ⇒ 처리 ⇒ 출력

함수도 프로그램 순서와 동일

**함수 사용방법**

일반화와 다양성을 확보하기 위해 함수에 이름을 주고,

매개변수를 함수 호출 시 **입력** 받은 후,

함수의 내부(body)에서 **처리**하고 return해서 함수의 결과 값을 **출력**한다.

```python
--------------------------------------- 
def factorial(n) : 
	sum = 1 
	for i in range(n, 1, -1) : 
		sum += i 
	return sum 

factorial(5) 
----------------------------------------- 

def 함수이름(처리할 매개변수) : 
	처리부분 
	return 출력할 값 반환 

함수호출(인자) 

----------------------------------------- 
```

프로그램은 함수가 함수를 호출하는 형식을 가짐.

그리고 컴퓨터의 구조는 함수를 베이스로 동작하게 만들어져 있음.

함수가 실행되고, 계산이 끝나고 나면 함수가 호출된 곳으로 돌아가 출력 된다.

이때 stack 메모리에 실행되어지는 데이터를 넣고, push→push→push→pop→pop→pop 등의 형태로 메모리에 쌓이고, 꺼내진다.

stack은 앞에서 배웠던 heap과 stack 메모리를 말함.

레고 블럭을 떠올리자

조그마한 레고를 조립하다 보면 큰 레고(조형물)이 만들어진다.

이처럼 작은 함수들이 모여서 시스템이 만들어 지고, 보이지 않는 추상화 개념이 쌓이게 된다.

레고 블럭을 크게 만들면 변화가 힘들듯이

함수도 **단일 책임의 원칙**이 있음

**단일 책임의 원칙 :**

한 가지 문제를 해결하는 내용으로 하나의 함수를 만드는 것

하나의 문제를 가진 함수들을 모아 큰 함수로 사용 함.

문제를 잘게 나누고 → 함수로 구현 → 레고 블록처럼 함수 조립 → 문제해결 + 시스템 생성

자바나 c에서는

데이터 타입에 따라서 함수의 이름을 각각 사용해야 해 ⇒ 오버로딩 사용

**오버로딩이란 ? 함수의 이름은 같은데 매개변수의 타입이나 개수가 다른 경우**

파이썬은 타입이 타입을 지정하지 않다 보니 위의 문제가 해결 됨.

매개변수 개수가 다른 문제는 default parameter를 사용해서 해결

정리하면,

파이썬에는 여러 번 함수를 정의할 수 없고 (오버로딩X) 

만들어진 형태로 매개변수가 들어와야 해.

**매개변수 정의:**  factorial(a, b=10)라고 하면 b가 기본 매개변수

**함수를 정의할 때**

1. **required**

똑같은 이름으로 오버로딩(함수를 정의)할 수 없기 때문에

정해진 파라미터 개수만큼 반드시 데이터가 주어져야 함.

1. **default**

매개변수를 만들 때 초기값을 지정해두면 함수를 호출할 때 인자 값으로 주지 않아도 됨.

default 파라미터는 앞에 있으면 안됨. 항상 뒤에 있어야 함.

1. **keyword parameter**

호출할 때, 파라미터 순서를 바꾸고 싶으면 key를 명시해주면서 인자를 넘겨줘야해.

factorial(b=5, a=10)

1. **variable length(*,**)**
- 를 하나 붙이면 리스트로 분리되서 들어감
- *를 두개 붙이면 딕셔너리 형태로 들어감.

**함수를 구현한다 = 알고리즘을 구현한다는 것 = 문제를 해결한다는 것**

알고리즘 ⇒ 문제를 해결하는 절차, 방법

통계학: y=ax+b ⇒ 상관관계

함수와 함수가 관계를 맺어지면서 이루어진다.

함수 내부에서 호출할 수도 있고, 함수 내부에서 매개변수를 줄 수도 있음

**객체**: 데이터를 담고 있음.

**클래스** : 객체와 함수를 묶어서 갖고 있는 애

내가 갖고 있는 **데이터를 전달하는 방법 2가지**

- **Call by value** : 함수를 call하는데 값으로 호출하겠다.
- **Call by reference** : 함수를 호출하는데 데이터를 전달해서 호출하겠다.

a =10

factorial(10) - call by value  => c에서 일반변수

factorial(a) - call by reference => 파이썬은 전부 주소전달, 원본에 영향을 미친다.

파이썬은 기본적으로 call by reference 방식

a = 10

b = a

b에 a의 주소가 담기듯 call by reference도 a변수를 인자값으로 넘겨주면 해당 주소 값의 데이터를 건드릴 수 있음.

원본에 다른 데이터를 대입하여 저장해 놓으면 call by reference가 중단이 됨(깨짐).

a=100 -> 이 주소가 새로 저장되기 때문에 a = 10 은 건들지 않음
