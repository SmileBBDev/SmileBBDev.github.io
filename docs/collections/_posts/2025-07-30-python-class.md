## 객체지향 프로그래밍과 클래스 이해하기

프로그래밍을 하다 보면 **데이터 관리**가 가장 큰 고민 중 하나입니다.  
예를 들어 성적 프로그램을 만든다고 할 때, 성적 데이터를 전역변수에 넣어두면 어디서든 접근할 수 있습니다. 하지만 문제는 **어떤 함수가 데이터를 건드렸는지 추적하기 어렵다**는 점입니다. 원치 않는 값이 나오면 모든 코드를 뒤져야 하는 상황이 발생하죠.  

이 문제를 해결하기 위해 나온 개념이 바로 **클래스(class)**입니다.  

---

### 클래스란 무엇인가?
- **비슷한 기능을 하는 함수와 데이터를 묶어 놓은 것**  
- `class 클래스명` 으로 선언  
- 클래스명은 직접 명명해야 함  
- 클래스 내부에는 **멤버변수**와 **멤버함수**가 존재  
- 즉, 클래스 = **멤버변수 + 멤버함수 + 메서드**

👉 쉽게 말해, **데이터와 그 데이터를 처리하는 기능을 하나의 틀(Template)로 묶어 놓은 것**

---

## 객체지향 프로그래밍의 4가지 핵심 개념

### 1. Encapsulation (캡슐화)
- 데이터를 보호하기 위해 접근 지정자를 둠  
- `public`, `private` 같은 키워드로 데이터 접근을 제어  
- C/Java는 기본이 `private`, 파이썬은 기본이 `public`  

### 2. Abstraction (추상화)
- 실세계 데이터를 필요한 요소만 추출해 정의  
- 내부 동작을 몰라도 사용할 수 있음 (호출 추상화)  
- 상속 시 인터페이스 추상화 개념이 등장  

### 3. Polymorphism (다형성)
- 같은 이름의 함수가 상황에 따라 다르게 동작  
- C++/Java: **오버로딩**으로 해결  
- 파이썬: 기본 매개변수(default parameter)로 유연하게 처리  

### 4. Inheritance (상속성)
- 부모 클래스의 기능을 자식 클래스가 물려받음  
- 필요에 따라 **오버라이딩(재정의)** 가능  
- 같은 이름의 함수라도 자식 클래스에서 다른 동작을 수행할 수 있음  

---

## 클래스와 객체의 관계
- **실세계 객체(Object)** → **Template(클래스)** → **Object(인스턴스)**  
- 클래스는 설계도(템플릿), 객체는 그 설계도로 만들어진 실제 데이터  

예시 
```python
class Student:
    def __init__(self, name, kor, eng, math):
        self.name = name
        self.kor = kor
        self.eng = eng
        self.math = math

    def get_average(self):
        return (self.kor + self.eng + self.math) / 3

# 인스턴스 생성
s1 = Student("홍길동", 90, 85, 95)
print(s1.get_average())  # 90.0
```

## 메모리와 인스턴스
- 클래스는 한 번만 정의(템플릿 생성)  
- 인스턴스는 호출할 때마다 새로운 데이터 공간을 할당  
- 객체는 **Heap 메모리**에 저장됨  
- 파이썬은 모든 것이 객체이므로 `new` 키워드 없이도 자동으로 동적 메모리 할당  
- **가비지 컬렉션**: 참조가 사라진 객체는 자동으로 메모리에서 해제  

## 클래스의 장점
- **데이터와 기능을 하나로 묶어 관리**  
- **재사용성**: 작은 레고 블록처럼 기능별로 조립 가능  
- **유지보수 용이성**: 어떤 함수가 데이터를 건드렸는지 추적 가능  
- **확장성**: 상속과 오버라이딩으로 다양한 기능 구현 가능

## 정리
성적 프로그램처럼 데이터를 다루는 경우, 전역변수로 관리하면 추적이 어렵기 떄문에  
**클래스**를 통해 데이터를 보호하고, 관련 기능을 묶어 관리하는 것이 객체지향 프로그래밍의 핵심!  

👉 클래스는 **작은 레고 블록**처럼 시스템을 구성하는 기본 단위이며, **캡슐화, 추상화, 다형성, 상속성**이라는 4가지 정신을 바탕으로 설계
