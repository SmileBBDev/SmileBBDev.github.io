## 관계형 데이터베이스(RDBMS) 심화 정리

데이터베이스는 **대량의 데이터를 저장하고 공유**하기 위해 만들어진 시스템입니다.  
관계형 데이터베이스(RDBMS)는 데이터를 **행과 열**로 관리하며, **중복을 최소화하고 무결성을 보장**하는 구조를 갖습니다.  

---

## 관계 (Relationship)

### 테이블 분할과 관계 형성
- **Primary Key (PK)**: 기본키, 유일한 값, Null 불가  
- **Foreign Key (FK)**: 외래키, 다른 테이블의 PK를 참조하여 관계 형성  
- **관계 목적**: 중복 배제, 메모리 절약, 효율적 관리  

### 제약 조건 동작 방식
- **No Action**: FK가 참조하는 PK가 없으면 동작 불가 (무결성 위배)  
- **Restrict**: FK가 참조 중이면 PK 삭제 불가  
- **Cascade**: 참조하는 데이터까지 자동 삭제  
- **Set Null**: 참조 데이터 삭제 시 FK를 Null로 변경  

### 관계 유형
- **1:1 관계**: 관리가 복잡할 때 테이블을 분리하여 연결  
- **1:N 관계**: 하나의 데이터가 여러 데이터와 연결  
- **N:M 관계**: 직접 연결 불가, 중간 테이블 필요  

---

## Join (조인)
두 개 이상의 테이블 데이터를 결합하여 조회하는 방법 

- **Inner Join**: 양쪽 조건에 맞는 데이터만 출력  
- **Left Join**: 왼쪽 테이블의 모든 데이터 출력, 오른쪽은 조건 맞을 때만 연결  
- **Right Join**: 오른쪽 테이블의 모든 데이터 출력  
- **Full Join**: 양쪽 모든 데이터 출력 (공통 + 개별 데이터)  

---

## Trigger (트리거)
테이블 간 연결된 관계에서 한쪽에 변화가 생기면 다른 테이블에도 영향을 주는 자동 동작.  

- 발생 시점: `insert`, `update`, `delete`  
- **Before / After** 구분  
- 데이터 참조:  
  - `insert`: new 데이터만 사용  
  - `update`: new + old 데이터 모두 사용  
  - `delete`: old 데이터만 사용  

👉 트리거는 **데이터 무결성 유지와 자동화**에 필수

---

## Transaction (트랜잭션)
데이터 신뢰성을 보장하는 단위 작업

- **commit**: 변경사항 반영  
- **rollback**: 오류 발생 시 이전 상태로 복구  
- **save point**: 특정 지점까지 실행 상태 저장  

`insert`, `update`, `delete`는 트랜잭션 대상, `select`는 조회만 수행

---

## 검색 (Search)

### 인덱스 (Index)
- **B-Tree 구조** 기반  
- PK와 Unique Key 지정 시 자동 인덱스 생성  
- PK: Null 불가  
- Unique Key: Null 허용  
- FK: Null 허용  

👉 인덱스를 통해 **정렬 + 이진 검색**으로 빠른 탐색 가능

### Select문 실행 순서
```sql
select 필드명
  from 테이블명
 where 조건
 group by 그룹필드
 having 그룹조건
 order by 정렬조건
 limit 제한조건
```
실행 순서: **from → where → group by → select → order by → limit**

---

## View (뷰)
- **가상 테이블**  
- 복잡한 `select`문을 단순화하여 재사용 가능  
- 실제 저장 공간 없음, 실행 시 생성  

## Event (이벤트)
- 지정된 간격/날짜에 자동 실행되는 작업  
- 예: 게임 접속 시 보상 지급, 정기적 데이터 업데이트  


## Stored Procedure (저장 프로시저)
- 여러 명령어를 묶어 함수처럼 호출 가능  
- 서버 측에서 실행 → 트래픽 감소  
- 공동 작업에 유리  
- 원하는 데이터를 미리 찾아두고 호출 시 반환  

---

## 프로그래밍적 요소
- **변수 대입**: `set` 사용  
- **제어문**: `if`, `case`  
- **반복문**: `loop`, `while`, `until`  
- **함수(Function)**: 값을 반환, 쿼리에서 사용  
- **프로시저(Procedure)**: 명시적 반환 없음, 원격 호출  

사용자 정의 함수/프로시저를 DB에 등록하여 활용 가능

---

## 데이터베이스 3대 요소
1. **공유성**: 여러 사용자/프로그램이 데이터 공유  
2. **무결성**: 데이터 정확성과 일관성 유지  
3. **보안성**: 권한 제어 및 데이터 보호  

---

## 클라이언트와 서버
- **HeidiSQL**: 클라이언트 도구  
- **MariaDB**: 서버 DBMS  
- 파이썬과 연결 시 특정 DB에 접근 가능  

### 파이썬과 RDBMS 연결 실습

```python
import pymysql

conn = pymysql.connect(
    host="localhost",
    user="root",
    password="비밀번호",
    db="school",
    charset="utf8"
)

cur = conn.cursor()
cur.execute("SELECT name, kor, mat, eng FROM student")
rows = cur.fetchall()

for row in rows:
    name, kor, mat, eng = row
    total = kor + mat + eng
    avg = total / 3
    print(f"{name} 총점:{total}, 평균:{avg:.2f}")
```

## 정리
관계형 데이터베이스(RDBMS)는 **관계, 검색, 트랜잭션, 자동화 기능**을 통해 대량 데이터를 효율적으로 관리합니다.  
- **PK-FK 관계**로 중복을 배제  
- **Join, Trigger, Transaction**으로 데이터 무결성과 자동화 확보  
- **Index, View, Stored Procedure**로 검색과 성능 최적화  
- **Event, 함수/프로시저**로 반복 작업과 트래픽 감소  

👉 결국 RDBMS는 **데이터 공유, 무결성, 보안성**을 핵심으로 하여, 프로그래밍적 사고와 동일한 원리로 운영
