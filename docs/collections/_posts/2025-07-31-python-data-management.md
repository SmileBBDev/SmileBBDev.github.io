## 대량의 데이터를 다루기 위한 자료구조와 클래스 활용

프로그래밍에서 중요한 주제 중 하나는 **대량의 데이터를 어떻게 효율적으로 관리할 것인가**입니다.  
이를 위해 다양한 **자료구조(Data Structure)**와 **클래스(Class)** 개념을 활용하게 됩니다.  

---

## 기본 자료구조

### 1. 리스트(List)
- 배열 단위이자 리스트 단위  
- 연속적인 메모리 공간에 데이터를 저장  
- 동적으로 확장 가능  
- `append()`, `pop()`을 통해 추가/삭제 가능  

### 2. 튜플(Tuple)
- 리스트와 동일한 구조  
- **수정 불가능(Immutable)**  

### 3. 딕셔너리(Dictionary)
- `key-value` 형태로 데이터 저장  
- 키를 통해 빠르게 값에 접근 가능  

### 4. 집합(Set)
- 범주형 데이터를 관리할 때 사용  
- 키 중심으로 데이터 관리  



## 사용자 정의 자료구조
사용자가 직접 정의할 수 있는 자료구조는 **함수(Function)**와 **클래스(Class)**입니다.  

- 클래스 인스턴스화 시 메모리에 생성되는 것은 **멤버변수만 확보**  
- 함수는 한 번만 정의됨  
- 클래스 내부의 멤버변수는 어떤 타입으로든 사용 가능  
- 클래스의 멤버함수는 리스트를 매개변수로 받을 수 있음  


## 클래스와 자료구조의 관계
클래스가 여러 개 있으면 자료구조와 연결 관계를 맺을 수 있습니다.  

- 리스트에 클래스를 담을 수 있음  
- 클래스 자체가 1차원 배열 형태로 `dict` 구조처럼 리스트에 들어감  
- 리스트 안에 리스트를 연결하면 2차원 배열처럼 구성 가능  

👉 즉, **자료구조와 자료구조가 연결 관계를 맺어 새로운 자료구조를 만들 수 있음**  

예시:  
- 리스트에 클래스 인스턴스를 담으면, 리스트는 클래스 인스턴스의 **메모리 주소**를 참조  
- 2차원 배열처럼 활용 가능  

---

## 변수와 메모리
- 모든 변수는 **주소값을 담고 있음**  
- 데이터를 직접 저장하는 것이 아니라, 메모리 주소를 참조하는 방식  

---

## 성적 프로그램 예시
리스트에 리스트로 성적 데이터를 관리하는 대신, 클래스를 활용하면 더 구조적으로 관리할 수 있습니다.  

```python
students = [
    {"name": "홍길동", "korea": 92},
    {"name": "파이썬", "korea": 92},
    {"name": "화이팅", "korea": 92}
]
```

- 입출력 데이터 타입: 문자  
- 데이터는 JSON 형태로 주고받음  
- 데이터는 이동하며 서로 관계를 맺음  

---

## 파이썬 클래스의 특징
1. **멤버변수와 멤버함수를 실시간으로 추가/삭제 가능**  
2. 멤버변수 = **attribute(속성)**  
   - `setattr`, `getattr`, `delattr`로 제어 가능  
3. `self` = 다른 언어의 `this`와 유사  

---

## 정리
- 대량의 데이터를 다루기 위해서는 **리스트, 튜플, 딕셔너리, 집합** 같은 기본 자료구조를 활용  
- 더 복잡한 구조와 기능을 위해 **클래스**를 사용  
- 클래스는 멤버변수와 멤버함수를 통해 데이터를 구조적으로 관리할 수 있으며, 다른 자료구조와 연결해 새로운 형태를 만들 수 있음  
- 파이썬 클래스는 유연성이 높아 실시간으로 속성을 추가/삭제할 수 있고, JSON 형태로 데이터를 주고받으며 다양한 관계를 표현할 수 있음
