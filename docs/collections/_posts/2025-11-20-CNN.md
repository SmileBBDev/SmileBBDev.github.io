# CNN(Convolutional Neural Network) 구조 및 원리 정리

## 1. 기본 개념

### Channel (채널)
- 이미지의 색상 정보를 담는 차원
- RGB 이미지 → 3개의 채널 (Red, Green, Blue)
- 흑백 이미지 → 1개의 채널

### Convolution (합성곱 연산)
- CNN의 핵심 연산으로 이미지 특징을 추출
- 필터(Filter, Kernel)를 입력 이미지 위에서 슬라이딩하며 곱셈과 덧셈 수행 → Feature Map 생성
- 예: 2×2 필터를 5×5 입력에 적용하면 4×4 출력 생성

### Filter (Kernel)
- 작은 크기의 행렬로 특정 패턴(모서리, 윤곽선 등)을 감지
- 여러 개의 필터 사용 시 다양한 특징 추출 가능 (Multi-filter)

### Padding
- 입력 이미지 가장자리에 0을 추가하여 출력 크기 조절 및 정보 손실 방지
- 종류: **valid** (패딩 없음), **same** (출력 크기를 입력과 동일하게 유지)

### Stride
- 필터가 이동하는 간격
- Stride=1 → 한 칸씩 이동 / Stride=2 → 두 칸씩 이동
- Stride가 커질수록 출력 크기는 작아짐

---

## 2. Pooling (풀링)

### Max Pooling (최대 풀링)
- 필터 영역 내 최댓값만 추출
- 특징을 유지하면서 크기를 줄이고 계산량 감소

### Average Pooling (평균 풀링)
- 필터 영역 내 평균값을 추출
- Max Pooling보다 부드러운 특징 추출

---

## 3. CNN 전체 구조 예시

1. 입력 이미지 (예: 고양이 vs 강아지 분류)  
2. Convolution Layer → 특징 추출  
3. Max Pooling Layer → 크기 축소  
4. Convolution Layer → 더 깊은 특징 추출  
5. Max Pooling Layer  
6. Flatten Layer → 2D → 1D 변환  
7. Fully Connected Layer (Dense) → 분류 수행  
8. 출력 → 예측 결과 (예: 고양이 or 강아지)

---

## 4. 추가 개념

### Activation (ReLU)
- 음수를 0으로 변환
- 비선형성 추가 → 복잡한 패턴 학습 가능

### Global Average Pooling (GAP)
- 각 채널마다 평균 하나만 남기는 방식
- Flatten 대신 사용 가능

### Grad-CAM (Gradient-weighted Class Activation Mapping)
- CNN이 이미지에서 어떤 부분을 보고 특정 클래스를 판단했는지 시각적으로 보여주는 기술

### ImageDataGenerator (Keras)
- 대용량 이미지 데이터를 실시간으로 불러오고 증강(Data Augmentation)하는 도구
- 메모리 문제 해결 및 과적합 방지

---

## 5. 프레임워크별 텐서 구조

### TensorFlow (NHWC)
- (Batch, Height, Width, Channel)
- 예: (1, 28, 28, 1)

### PyTorch (NCHW)
- (Batch, Channel, Height, Width)
- 예: (1, 3, 256, 256)

### Conv2D 커널 구조 (TensorFlow)
- (kernel_height, kernel_width, in_channels, out_channels)
- 예: (3, 3, 1, 1)

---

## 6. 기타 필터 및 연산

- Sobel X: 가로 방향 미분 → 세로 에지 감지  
- Sobel Y: 세로 방향 미분 → 가로 에지 감지  
- Gaussian Filter: 이미지 블러 처리

---

## 7. 학습 과정에서의 필터
- 필터의 개수는 지정하지만, 필터의 종류(패턴)는 학습 과정에서 신경망이 스스로 학습
- 초기 필터는 무작위 값(random weights)

## 핵심 요약
- CNN은 **합성곱(Convolution)**으로 특징을 추출하고, Pooling으로 크기를 줄이며,
Fully Connected Layer에서 최종 분류를 수행한다.
- 필터는 학습 과정에서 자동으로 최적화되며, GAP, Grad-CAM 등 다양한 기법으로 성능과 해석력을 높일 수 있다.
