## 데이터 타입
1. int/float - 정수/실수(숫자)
2. bool  - True/False로 이뤄진 논리형 데이터 타입
3. None - 타입 모를 때, 변수라고 선언하기 위해 사용 + 리턴하는 값이 없으면 None을 리턴
4. str - 문자열(String)

→ 파이썬은 변수에 주소값을 지정하기 때문에 데이터 타입이 무엇이든 모두 대입 가능

## 배열
### 배열 자료구조의 특징
1. 연속적인 메모리 공간 사용
- 배열은 메모리상에 연속적으로 배치되어야 함
- 인덱스를 통해 접근
- 각각의 요소에 주소를 직접 관리하지 않음

2. 동일한 데이터 타입
- 배열 내 모든 요소는 같은 데이터 타입으로 지정

3. 빠른 접근 용이
- 인덱스로 원하는 요소에 바로 접근 가능

### 데이터 검색과 배열
1. 배열에 데이터를 저장하는 이유 : 나중에 꺼내 쓰기 위해
2. 데이터를 꺼내려면 **검색(search)** 필요
3. 정렬된 배열은 **이진 검색(Binary Search)** 가능
4. 효율적인 검색방법 : **정렬(Sorting)**이 선행되어야 함

### 배열에 데이터 추가/삭제의 문제점
1. 고정된 크기의 **연속 메모리 공간** 사용
2. 특정 위치에 데이터를 삽입/삭제하려면 기존 배열을 **복사** 후 요소**이동**을 해야 함
