## 데이터 타입
1. int/float - 정수/실수(숫자)
2. bool  - True/False로 이뤄진 논리형 데이터 타입
3. None - 타입 모를 때, 변수라고 선언하기 위해 사용 + 리턴하는 값이 없으면 None을 리턴
4. str - 문자열(String)

→ 파이썬은 변수에 주소값을 지정하기 때문에 데이터 타입이 무엇이든 모두 대입 가능

## 배열
### 배열 자료구조의 특징
1. 연속적인 메모리 공간 사용
- 배열은 메모리상에 연속적으로 배치되어야 함
- 인덱스를 통해 접근
- 각각의 요소에 주소를 직접 관리하지 않음

2. 동일한 데이터 타입
- 배열 내 모든 요소는 같은 데이터 타입으로 지정

3. 빠른 접근 용이
- 인덱스로 원하는 요소에 바로 접근 가능

### 데이터 검색과 배열
1. 배열에 데이터를 저장하는 이유 : 나중에 꺼내 쓰기 위해
2. 데이터를 꺼내려면 **검색(search)** 필요
3. 정렬된 배열은 **이진 검색(Binary Search)** 가능
4. 효율적인 검색방법 : **정렬(Sorting)**이 선행되어야 함

### 배열에 데이터 추가/삭제의 문제점
1. 고정된 크기의 **연속 메모리 공간** 사용
2. 특정 위치에 데이터를 삽입/삭제하려면 기존 배열을 **복사** 후 요소**이동**을 해야 함
3. 삽입/삭제 연산이 **비효율적**이고 **메모리 사용에 부담**을 줌

| 항목 | 설명 |
| --- | --- |
| 메모리 | 연속적인 공간에 배치되어야 함 |
| 타입 | 모든 요소는 동일한 데이터 타입 |
| 접근 속도 | 빠름 (O(1)) |
| 검색 | 정렬이 되어 있다면 이진검색 가능 |
| 삽입/삭제 | 비효율적, 메모리 낭비 우려 |


## Data structure
### List (리스트)
1. 동적 크기 조절 가능
2. 연속적인 공간이 아니더라도 주소 연결로 메모리를 효율적으로 사용 가능
3. 새로운 데이터 삽입과 삭제 유리
4. 다양한 타입 저장 가능
5. 일반적인 데이터 모음 처리에 적함→ 고속 처리는 어려움
6. NumPy가 고속 데이터 처리 가능하도록 대체 → Numpy : 배열+선형대수

### Tuple (튜플)
1. 함수에 매개변수로 데이터를 전달할 때 사용, 속도가 빠르기 때문에 사용
2. 리스트와 사용법은 동일, 문법이 유사하지만 수정은 불가
3. 시스템에서 주로 사용, 직접 사용하는 경우는 거의 없음

### dict (딕셔너리)
1. key -value(데이터)구조
2. key를 주소처럼 사용 가능(데이터 자체를 주소로 만들어 놓음)
3. 규칙 기반 데이터 저장제 적합함
4. 중복 없는 키로 고속 조회 가능, 빠른 데이터 검색 가능.
5. ++ 해시함수 - 가능한 중복되지 않는 숫자가 나올 수 있도록

### set
1. 중복을 불허하고, key만 들어있는 자료형
2. 정해진 순서 없고, 범주형 데이터를 만들 때 사용한다.
3. 데이터 유일성 보장, 합집합/교집합/차집합 처리에 유용
