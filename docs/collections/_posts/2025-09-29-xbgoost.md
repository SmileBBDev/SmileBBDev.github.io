## XGBoost(Extreme Gradient Boosting) : booster
- 부스팅(Boosting) 기반 알고리즘 -> 약한 학습기(Weak Learner)를 여러 개 결합해서 강한 학습기(Strong Learner)로 만듦
- 목표는 **손실함수의 최소화**(오차를 줄이는 방향으로 학습)

## Ensemble 학습 기법
- 여러 모델을 조합해서 성능을 높이는 방법
- 종류 : Bagging, Boosting, Voting, Stacking, Blending
  - Bagging
    - 같은 알고리즘을 여러 데이터 샘플로 학습
    - 결과를 평균 또는 투표로 결합
    - ex:`RandomForest`, `Bagged Decision Trees`
  - Boosting
    - 이전 모델의 오류를 보완하는 방향으로 순차적 학습
    - 약한 학습기를 강한 학습기로 변환
    - ex: `AdaBoost`, `Gradient Boosting`, `XGBoost`, `LightGBM`, `CatBoost`
  - Voting
    - 서로 다른 모델의 예측 결과를 투표로 결합
    - 단순 다수결 또는 가중치 기반
    - ex: `VotingClassifier`(scikit-learn)

  - Stacking
    - 여러 모델을 학습한 후, 그 예측값을 기반으로 메타 모델을 학습
    - ex: `StackingClassifier`(scikit-learn)
  - Blending
    - Stacking과 유사, 훈련/검증 데이터 분할 방식이 다름
    - 보통 validation set을 따로 떼어 메타 모델 학습에 사용
