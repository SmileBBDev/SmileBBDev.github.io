## 🧠 R 언어의 특징

- **통계 기반 언어**
    - **통계학과 데이터 분석**을 이해하기 위해 설계된 언어
    - 파이썬으로는 이해하기 어려운 **통계 개념을 내장**함 - 통계적 사고를 기반으로 구성
    - **선형대수와 통계학**을 직관적으로 다룰 수 있도록 설계
- **객체 지향 프로그래밍(OOP - Object-oriented programming)**
    - 모든 데이터, 함수, 차트 등이 **객체(object)**로 관리됨
    - 클래스 생성 없이 함수 기반으로 작동
    - new 키워드 없음, 대부분 함수로 처리
    - 특별한 알고리즘 구현 시 클래스 사용 가능
    - c처럼 프로그래밍 함.
- **함수 중심 구조 (함수형 프로그래밍)**
    - 대부분의 작업은 **함수 호출**로 처리
    - 함수 이름에 .이 포함되어도 하나의 단어로 인식됨 (예: as.integer - 하나의 함수 이름임 )
- **고속 처리와 병렬 연산 - 벡터 연산 중심 (vector)**
    - 기본 자료구조가 벡터
    - 벡터 간 요소 연산 자동 처리
    - for문 사용 빈도 낮음 → 벡터화 연산으로 대체
    - 멀티코어 CPU 활용으로 대량 데이터 고속 처리
    - 멀티코어는 여러개의 코어가 들어가있는 것
- **동적 타입(Dynamically Typed)**
    - 변수 선언 시 데이터 타입 지정 불필요
    - 이질적 데이터 혼합 시 강제 형 변환 발생 (예: 숫자 + 문자 → 문자로 변환)
- **메모리 기반 처리 (In-Memory Computing)**
    - 빠른 처리 속도
    - 단점: 메모리 크기에 따라 처리 한계 발생
    - 대용량 데이터는 **Spark, Hadoop 등 외부 시스템과 연동**
    - Hadoop(하둡) - 병렬처리, 삭제명령은 없음, 분석용
    - Spark - 많이 사용 됨.
- **시각화(Visualization)**
    - 강력한 그래픽 기능 제공
    - 분석 결과에 통찰을 부여하는 시각화 지원
- **패키지 생태계 (package)**
    - 다양한 통계 및 분석 패키지 제공(통계, 시각화, 머신러닝 등)
    - 내장 통계 함수가 풍부함
    - 통계를 기반으로 만들어진 언어

## 🧱 R의 자료구조

| 자료구조 | 설명 | 특징 |
| --- | --- | --- |
| **Vector** | - 기본 자료구조 | 동질적 데이터만 저장 가능- 요소 단위 연산 가능 |
| **Matrix** | - 2차원 벡터- 선형대수 기반 | 방향과 크기를 가진 데이터 표현 |
| **Array** | - 다차원 배열 | 벡터와 유사하지만 차원이 더 많음, 여러 개의 매트릭스를 포함 |
| **Data Frame** | - 표 형태의 데이터 | 열 내 동질적, 열 간 이질적- 열마다 다른 데이터 타입 허용 |
| **List** | - 이질적 데이터 저장 가능 | 크기/형태가 다른 데이터 저장 가능, 특별한 경우에 사용
Python의 list와 유사 |

> 🔎 참고:
> 
> 
> Python은 list, tuple, dict, set  - list에 이질적 데이터 저장
> 
> JavaScript는 object, array 중심, json 등장
> 
> R은 벡터 중심이며, 이질적 데이터는 강제 형 변환됨
>

### 🔍 벡터(Vector)

- R의 **기본 단위**
- 모든 데이터는 벡터로 인식됨 (스칼라도 벡터로 처리)
- **동질적 자료형**만 저장 가능 → 이질적일 경우 **자동 형 변환**
- 예: 숫자 + 문자 → 모두 문자로 변환됨

### 📊 데이터 프레임(Data Frame)

- 열(column) 단위로 구성
- **열 내 동질적**, **열 간 이질적**
- 통계학에서는 **열 중심 분석**이 중요 (패턴, 규칙 탐색)
- 열내 동질적(영어, 수학 컬럼 안에 있는 데이터), 열간 이질적(이름, 국어, 영어, 수학 각각 type이 다름)
- 하나의 열 안에서는 동질적으로 데이터가 구성되어 있어야 하니까 열내 동질적이고 각각의 열 마다는 데이터 타입이 다 다르니까 열간 이질적

### 🧮 리스트(List)

- 벡터와 달리 **이질적 데이터** 저장 가능
- 벡터 크기가 다르거나, 매개변수 전달/결과 반환 시 사용
- vactor -> data frame -> array 와 같이 사각형 구조가 되어야 함.
- 사각형 구조가 아닌 경우 → NA 발생

## ⚙️ 함수와 메모리 처리 방식

- **Call by Value**
    - 변수는 객체의 주소를 담고 있지만, 함수에 전달 시 값 복사 발생
    - 복사로 인해 원본 데이터는 변경되지 않음
    
    <aside>
    💡
    
    객체지향은 전부 주소를 담고 있고, 변수가 주소를 담고 있으면 call by reference가 등장함.
    
    그러나 R은 주소를 담고 있지만 call by value로 작동 ⇒ 값이 복사가 이루어짐.
    
    </aside>
    
- **형 변환 함수 예시**
    - `as.integer()`, `is.integer()` 등
    - 데이터 타입 확인 및 변환에 사용

## 📐 데이터 처리 철학

- **열 중심 분석**: 전체 속에서 패턴과 규칙을 찾는 것이 목적
- **평균만으로는 부족** → **분산**을 통해 질적 차이 분석
- 평균으로 데이터를 조회하면 정확성을 잃을 수 있고, 의미를 잃어버릴 수 있기 때문에
- **NA vs NULL**:
    - `NA`: 결측치 (데이터 중 일부가 빠짐)
    - `NULL`: 데이터 자체가 없음
