## 1️. 퍼셉트론 : 신경망의 시작점

### 💡 핵심 개념
퍼셉트론(Perceptron)은 **가장 기본적인 인공신경망의 단위**  
입력값에 가중치를 곱하고, 그 결과를 활성화 함수로 판정

$$y = f(w_1x_1 + w_2x_2 + b)$$

예시)

| 입력 | 결과 |
| --- | --- |
| 비가 온다(x₁)=1, 우산 있음(x₂)=1 | 나간다(y)=1 |
| 비가 온다(x₁)=1, 우산 없음(x₂)=0 | 나간다(y)=0 |

👉 입력 조건을 받아 결과를 분류하는 가장 단순한 모델이 퍼셉트론

---

## 2️. 한계와 확장 : MLP (다층 퍼셉트론)

퍼셉트론은 직선(초평면)으로만 데이터를 나눌 수 있어 **비선형 문제(XOR 등)**를 해결하지 못함     
이를 극복하기 위해 **Layer(층)**를 여러 개 쌓은 구조가 **MLP(Multi Layer Perceptron)**


## 3️. MLP 구조 : 행렬곱으로 보는 Layer

> “Layer를 추가한다 = 행렬곱을 여러 번 수행한다”

각 층은 입력 데이터와 가중치 행렬을 곱한 뒤 활성화 함수를 통과시켜 다음 층으로 전달

$$ h = f(XW + b) $$

예시:
- 입력 데이터 X: [x₁, x₂, x₃] (3개 특성)
- 출력 뉴런 4개 → 3×4 가중치 행렬(W)이 필요

👉 즉, **입력 3개가 4개의 특징으로 변환되도록** 내부에 3×4개의 가중치가 자동으로 생성  
훈련 과정에서 이 값들이 업데이트되며, 모델이 스스로 학습

---

## 4️. 행렬곱과 특징 추출

- **내적(행렬곱)**: 앞의 데이터가 뒤의 기준축(가중치)에서 어떤 특징을 가지는지 비교하는 과정  
- **차원 확장 (Feature Expansion)**: 출력 뉴런을 늘려 더 많은 특징을 추출  
- **차원 축소 (Feature Reduction)**: 불필요한 특징을 줄이고 핵심만 남김

💡 Layer는 “데이터를 다른 기준으로 바라보게 만들어주는 변환기”

---

## 5️. 딥러닝 : Layer를 깊게 쌓는다는 것

Layer를 많이 쌓기:
- 행렬곱을 여러 번 수행한다는 뜻
- 매 Layer마다 데이터의 특징을 더 세밀하게 추출한다는 의미

- CNN, RNN 같은 구조도 결국 **“Layer를 어떻게 쌓느냐”**의 차이

---

## 6️. 순전파 (Forward Propagation)

입력에서 출력까지 예측값을 만드는 과정
1. 입력 데이터 → 첫 Layer에서 행렬곱
2. 활성화 함수(ReLU, Sigmoid 등) 적용
3. 다음 Layer로 전달
4. 마지막 Layer에서 결과 출력

---

## 7️. 활성화 함수 (Activation Function)

행렬곱만 하면 선형 관계만 표현 → 비선형 패턴 학습을 위해 필요

| 함수 | 수식 | 특징 |
| --- | --- | --- |
| Sigmoid | $\(\frac{1}{1+e^{-x}}\)$ | 0~1 압축, 이진분류 |
| tanh | $\(\frac{e^x - e^{-x}}{e^x + e^{-x}}\)$ | -1~1, 중심 0 |
| ReLU | $\(\max(0,x)\)$ | 음수 제거, 연산 빠름 |

👉 ReLU는 음수를 잘라내고 양수만 전달 → 학습 속도 ↑, 효율 ↑

---

## 8️. Softmax와 확률 변환

출력층에서는 결과를 확률로 변환

$$ \text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}} $$

- **이진분류**: Sigmoid
- **다중분류**: Softmax


👉 최종 결과는 0~1 사이 확률값으로 표현

---

## 9️. 손실함수 (Loss Function)

예측과 실제의 차이를 수치화

| 손실함수 | 사용 | 의미 |
| --- | --- | --- |
| MSE | 회귀 | (예측-실제)² |
| Cross Entropy | 분류 | 확률 기반 오차 |

### 로그가 필요한 이유
- 확률과 비용은 역함수 관계  
- 정답 확률이 낮을수록 손실이 커져야 함  
- 로그가 이 관계를 만들어줌

예:
- 정답 확률 0.9 → $-log(0.9)=0.1$ (손실 작음)
- 정답 확률 0.1 → $-log(0.1)=2.3$ (손실 큼)

👉 Cross Entropy는 “정답 확률이 낮을수록 손실을 크게 만든다”

---

## 역전파 (Backpropagation)

손실을 기반으로 가중치를 수정

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

- η: 학습률(Learning rate)  
  - 크면 → 진동  
  - 작으면 → 느림  
  - 보통 처음엔 크게, 점점 줄임

---

## 학습 최적화 기법

- **Momentum**: 이전 이동방향을 기억해 진동 억제  
- **Solver (최적화 알고리즘)**:
  - SGD: 빠름, 일부 샘플만 사용
  - Adam: 학습률+모멘텀 자동조절 (가장 널리 쓰임)
  - LBFGS: 작은 데이터셋에 적합

---

## RBM (Restricted Boltzmann Machine)

RBM은 신경망 초기 모델로,  
입력층 → 잠재층으로 데이터를 압축하며 **숨겨진 특징(feature)**을 자동 추출  
AutoEncoder, Deep Belief Network의 기반이 된 모델

---

## 전체 흐름 요약

| 단계 | 과정 | 설명 |
| --- | --- | --- |
| 1 | 데이터 입력 | 여러 특징(feature)들이 모델에 들어옴 |
| 2 | 행렬곱 | 입력×가중치 = 새로운 표현 |
| 3 | 활성화 함수 | 비선형성 추가 |
| 4 | Softmax/Sigmoid | 확률값 계산 |
| 5 | 손실함수 | 예측과 실제 차이 계산 |
| 6 | 역전파 | 가중치 수정 |
| 7 | Learning rate/Momentum | 학습 강도 조절 |
| 8 | Solver | 최적화 방식 선택 |
| 9 | RBM | 특징 자동 추출 |


## 직관적 비유

| 개념 | 비유 |
| --- | --- |
| 행렬곱 | 재료(데이터)를 섞는 과정 |
| 활성화함수 | 불필요한 재료는 버리고 유효한 부분만 남김 |
| Softmax | 결과를 확률로 표현 |
| 손실함수 | 틀린 정도를 점수로 계산 |
| 역전파 | 오답노트 작성 |
| 학습률 | 공부 강도 조절 |
| Momentum | 이전 공부 방향 유지 |
| Solver | 공부 전략 선택 |
| RBM | 숨겨진 패턴 자동으로 찾는 보조 뇌 |

---

## 결론

- 퍼셉트론 → 오류 기반 학습의 시작점  
- MLP → 행렬곱과 Layer로 복잡한 특징 학습  
- 딥러닝 → Layer를 깊게 쌓아 복잡한 패턴 포착  
- Softmax → 결과를 확률로 변환  
- Cross Entropy → 오차를 수치화  
- Backpropagation → 손실을 줄이기 위해 가중치 수정  
- Learning rate + Momentum + Solver → 효율적 학습  
- RBM → 숨겨진 특징 자동 추출

👉 신경망은 **“데이터를 입력받아 예측을 만들고, 틀린 만큼 스스로 수정하며 점점 똑똑해지는 구조”**
