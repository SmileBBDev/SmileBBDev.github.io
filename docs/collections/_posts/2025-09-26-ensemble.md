## Decision Tree와 Ensemble 
머신러닝에서 **트리 기반 모델(Tree Model)**은 직관적이고 강력한 도구  
특히 **Decision Tree(의사결정트리)**와 이를 확장한 **Random Forest, Boosting, Stacking** 같은 앙상블 기법은 실무와 시험 문제에서 자주 등장합니다. 이번 글에서는 트리 모델과 앙상블 학습을 체계적으로 정리해봅니다.

---

## 1. Decision Tree (의사결정트리)

### 기본 개념
- 데이터를 **이진트리(Binary Tree)** 구조로 분할하여 예측/분류를 수행
- Root Node → 내부 노드 → Leaf Node로 이어지는 구조
- Iris 데이터 예시:  
  - 종: 3개 (Setosa, Versicolor, Virginica)  
  - 각 종당 50개 데이터  
  - 변수: 4개 독립변수 + 1개 종속변수

### 분할 기준: 불순도
- **엔트로피(Entropy)**  
- **지니계수(Gini Index)**  
- **카이제곱(Chi-square)**  

👉 불순도가 작아지고 정보이득이 커지는 방향으로 데이터를 분할    
불순도가 0이면 완벽하게 분리된 상태

---

## 2. Decision Tree 하이퍼파라미터

트리 모델은 **깊이와 분할 조건**에 따라 성능이 크게 달라짐

- **max_depth**: 트리의 최대 깊이  
  - 너무 깊으면 과적합(overfitting) 발생  
  - 규제를 통해 방지
- **min_samples_split**: 노드를 분할하기 위한 최소 샘플 수  
- **min_weight_fraction_leaf**: Leaf 노드에 최소 가중치 비율 설정  
  - 소수 데이터에도 가중치를 부여해 균형 잡힌 학습 가능
- **max_features**: 분할 시 고려할 변수 개수  
  - 전체 변수 중 일부만 선택해 모델 다양성 확보

👉 하이퍼파라미터 튜닝은 **Grid Search CV** 같은 교차검증(Cross Validation) 기법으로 수행

---

## 3. Random Forest

### 개념
- 여러 개의 Decision Tree를 만들어 **앙상블**하는 기법
- 각 트리는 일부 변수와 일부 데이터만 사용 (Bootstrap 샘플링)
- 분류 문제 → **투표(Voting)**  
- 회귀 문제 → **평균(Averaging)**

### 장점
- 단일 Decision Tree의 불안정성을 극복  
- 분산(Variance)을 줄여 안정적인 결과 도출  
- 과적합 방지 효과

👉 Random Forest는 **Bagging 기법**의 대표적인 예

---

## 4. Bagging vs Boosting

### Bagging (Bootstrap Aggregating)
- 데이터 샘플을 여러 번 뽑아 여러 모델 학습  
- 결과를 평균(회귀) 또는 투표(분류)로 결합  
- 대표: **Random Forest**

### Boosting
- 약한 모델(Weak Learner)을 순차적으로 학습시켜 강한 모델로 발전  
- 오분류된 데이터에 더 큰 가중치를 부여  
- 대표 알고리즘:
  - **AdaBoost**: 오분류 데이터에 가중치 ↑
  - **Gradient Boosting**: 이전 모델의 오차를 다음 모델이 보완
  - **XGBoost, LightGBM, CatBoost**: 성능 최적화된 최신 Boosting 기법

👉 Boosting은 **Bias(편향)**를 줄이는 데 효과적

---

## 5. Ensemble 학습 기법

앙상블은 여러 모델을 결합해 성능을 높이는 방법

- **Voting**: 여러 모델의 결과를 투표/평균으로 결합  
- **Blending**: 서로 다른 모델의 결과를 단순 결합  
- **Stacking**: 1차 모델들의 결과를 다시 2차 모델에 학습시켜 최종 예측  
  - 교차검증(CV)을 적용하면 Stacking  
  - 적용하지 않으면 Blending

---

## 6. Bias vs Variance Trade-off

- **Bias(편향)**: 모델이 단순해서 데이터 패턴을 잘 설명하지 못하는 경우 → 과소적합  
- **Variance(분산)**: 모델이 너무 복잡해서 데이터에 과도하게 맞춘 경우 → 과적합  
- Decision Tree는 Variance가 큰 편 → Random Forest로 분산을 줄임  
- Boosting은 Bias를 줄이는 데 효과적

---

## 정리

- **Decision Tree**: 직관적, 하지만 불안정 → 과적합 위험  
- **Random Forest**: Bagging 기반, 분산 감소, 안정적 성능  
- **Boosting**: 순차적 학습, 오분류에 가중치, Bias 감소  
- **Ensemble 기법**: Voting, Blending, Stacking으로 모델 결합  
- **하이퍼파라미터 튜닝**: max_depth, min_samples_split, max_features 등 → Grid Search CV 활용

👉 결국, 트리 기반 모델은 단일 트리보다 **앙상블(Random Forest, Boosting)**을 통해 더 강력하고 안정적인 성능을 발휘한다.
