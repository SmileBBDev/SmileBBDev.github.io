## 데이터 전처리
### 데이터 전처리란?
  데이터 전처리는 지처분한 책상을 깨끗하게 치우듯

>  데이터를 분석하거나 AI에게 학습시키기 전에 
>
> **데이터를 깨끗하게, 똑똑하게 만드는 과정!**

분석이나 모델링 전에 데이터를 정리하고 다듬는 필수 단계

### 데이터 전처리 과정

| 단계 | 설명 | 예시 |
| --- | --- | --- |
| 1️⃣ 준비하기 | 여러 데이터를 모아서 하나로 합치기 | 여러 반 친구 명단을 하나로 만들기 |
| 2️⃣ 결측치 처리 | 빠진 값 채우기 | 이름이 없는 친구는 "모름"이라고 적기 |
| 3️⃣ 이상치 처리 | 너무 이상한 값 제거 | 키가 300cm인 친구는 잘못된 거니까 빼기 |
| 4️⃣ 정규화 | 숫자 크기 맞추기 | 점수 0100을 01로 바꾸기 |
| 5️⃣ 범주화 | 그룹 나누기 | 점수로 "우수", "보통", "미달"로 나누기 |
| 6️⃣ 불균형 처리 | 데이터 양 맞추기 | A반은 100명, B반은 10명이면 B반을 늘리기 |
| 7️⃣ 저장하기 | 정리된 데이터를 저장 | 정리된 명단을 파일로 저장하기 |

### 단계별 데이터 전처리 개념

**2️⃣ 결측치 처리** (Missing Values)

- 빠진 값이 있으면 평균이나 "모름"으로 채우거나 제거
- 함수: `fillna()`, `dropna()`, `isnull()`, `interpolate()`, `impute()`, `replace()`

**3️⃣ 이상치**(Outliers)

- 너무 크거나 작은 값은 이상한 값!
- 방법:
    - **IQR**: 사분위 범위 벗어난 값
    - **Z-score**: 평균에서 너무 멀리 떨어진 값
    - **Clipping**: 상한/하한값으로 잘라내기
- 시각화: `boxplot`

**4️⃣ 정규화**(Normalization)

- 숫자 크기를 비슷하게 맞추는 단계(데이터 크기 맞추기)
- 방법:
    - `min-max`: 0~1 사이로
    - `z-score`: 평균 기준으로 얼마나 떨어졌는지, 평균0/표준편차1
    - `robust`: 중앙값 기준으로 정규화
    - **벡터 정규화**: 방향만 남기고 크기 통일
    

**5️⃣ 범주화**(Categorization)

- 숫자나 문자열을 그룹으로 나누는 단계
- 방법:
    - `cut()`: 구간 나누기
    - `qcut()`: 분위수 기반
    - `get_dummies()`: one-hot 인코딩
    - `factorize()`, `categorical()`: 순서 부여

**6️⃣ 데이터 균형 맞추기**

- A 데이터가 너무 많고 B가 적으면 편향 벌생
- 해결 방법:
    - **🔼 오버샘플링**: B 데이터를 늘리기 (예: KNN - 근접한 데이터 조합, 클러스터링 + Shaking - 그룹 내에서 변형)
    - **🔽 언더샘플링**: A 데이터를 줄이기, 정보 손실 가능

## 모델과 전처리의 연결

### 언더피팅

- 데이터가 너무 적거나 단순할 때 발생
- 해결: 데이터 늘리기, 변수 확장

### 랜덤포레스트 + 부스팅

- 여러 모델을 만들고 결과를 **투표** 또는 **평균**
    - **투표**: 분류 문제
    - **평균**: 회귀 문제



## 이미지 & 텍스트 데이터 전처리

### 이미지

- 픽셀값 0과 1로 나눔
    
    255 → 0
    
- 방법: `/255` → 부동소수점 이미지
- 증강: 회전, 반전, 이동 → **데이터 증강(Data Augmentation)**

### 텍스트

- 정제: 특수문자 제거, 소문자 변환
- 인코딩: `one-hot`, `embedding`



## 노이즈 처리

- 센서 데이터는 잡음이 많음
- 해결 방법:
    - **PCA**: 주요 정보만 추출
    - **구간 범주화**: 노이즈 완화



## 변수 중요도 & 가중치

- 모든 변수가 종속변수에 **동일한 영향**을 주는 건 아님
- 해결: **정규화**로 영향력 통일 또는 **가중치 부여**로 중요도 반영
