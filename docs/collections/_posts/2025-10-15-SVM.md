## **SVM(Support Vector Machine)**

### SVM 개요

- **목적:** 데이터를 나누는 **최적의 결정 경계(초평면, Hyperplane)** 를 찾는 것
- **핵심 아이디어:**
    - 각 클래스(양성/음성) 사이의 **Margin(여백)** 을 최대화
    - **Support Vector** : 결정 경계에 가장 가까운 데이터 포인트들
    - 이 포인트들만으로 경계를 정의 → **최적화 문제(Optimization)** 로 해결

### SVM(Support Vector Machine)의 모델 종류
**< SVM(Support Vector Machine) 모델의 하위 클래스 >** 
1. **SVC(Support Vector Classification)** - SVM을 사용한 분류 모델 <br>
   예: 고양이 vs 강아지
2. **SVR(Support Vector Regression)** - SVM을 사용한 회귀 모델 <br> 예: 집값 예측, 온도 예측

| 구분 | 모델명 | 설명 |
| --- | --- | --- |
| **지도학습** | `svm.LinearSVC` | 선형 SVM (이진/다중 분류용) |
|  | `svm.NuSVC` | 오류 허용 비율(ν)로 제어하는 SVC |
|  | `svm.SVC` | 일반적인 커널 SVM |
|  | `svm.LinearSVR` | 선형 회귀용 SVM |
|  | `svm.NuSVR` | 오류 허용 비율(ν) 기반 회귀용 SVM |
|  | `svm.SVR` | 커널 회귀용 SVM |
| **비지도학습** | `svm.OneClassSVM` | 정상 데이터만으로 학습 → 이상치 탐지용 |

### SVM의 주요 구성 요소

| 항목 | 의미 |
| --- | --- |
| **Margin Optimization** | 경계와 데이터 간의 여백을 최대화 (두 클래스 사이의 여유 공간 최대화) |
| **Optimal Hyperplane** | 마진이 최대가 되는 최적의 분리 선 (두 클래스를 가장 잘 나누는 선) |
| **Support Vectors** | 결정 경계를 정의하는 가장 가까운 샘플들 |
| **Kernel Function** | 비선형 데이터를 선형적으로 분리할 수 있도록 고차원으로 변환 <br> (데이터를 고차원으로 보내서 선형 분리가 가능하게 함) |

## **퍼셉트론(Perceptron)**

### 퍼셉트론(Perceptron)이란?

이진 분류기 : 두 개의 클래스를 나누는 선을 학습

**기울기(w)**와 **절편(b)**을 반복 학습을 통해 구함

**선형 분류기**로 작동, 딥러닝의 기본 단위

### 퍼셉트론(Perceptron)과 SVM의 관계

| 항목 | 퍼셉트론 | SVM |
| --- | --- | --- |
| **유형** | 이진 분류 | 이진 분류 (다중 분류는 확장형) |
| **학습 방식** | 데이터 하나씩 보면서 가중치/절편 갱신 <br> 선형 결정 경계 | 전체 데이터 기반 최적화로 경계 계산 <br> 마진 최대화 |
| **손실 함수** | Hinge Loss (이진분류) | Hinge Loss 기반 |
| **다중분류** | OVO, OVR 방식 | 내부적으로 자동 처리 |
| **결과물** | 직선(기울기, 절편) | 서포트 벡터, 초평면(법선 벡터 w와 절편 b) |
| **커널 사용** | 없음 | 커널 트릭으로 고차원 분리 가능 |
| **차이점** | 단순 선형 분리 | 마진을 최대로 하는 경계 최적화 |

### 다중 분류 시 SVM 구조

- SVM은 본질적으로 **이진 분류기**
- 다중 분류 시 내부적으로 다음 두 가지 전략 사용

| 구분 | 설명 | 예시 |
| --- | --- | --- |
| **OvO (One-vs-One)** | 클래스 쌍마다 1:1 비교 | n개의 클래스 → nC2개의 모델 생성 |
| **OvR (One-vs-Rest)** | 하나의 클래스 vs 나머지 전체 | n개의 클래스 → n개의 모델 생성 |

### 수학적 요소 (법선, 내적, 외적)

| 개념 | 설명 |
| --- | --- |
| **법선 벡터 (Normal Vector)** | 초평면의 방향을 결정하는 벡터 (SVM의 w와 동일) |
| **내적 (dot product)** | 두 벡터가 직교하는지 확인 (직교 → 법선 관계) |
| **외적 (cross product)** | 3차원 이상에서 평면을 만드는 벡터 계산에 사용 |
| **SVM에서는 내적을 사용** | 외적은 거의 사용하지 않음 (주로 물리/기하 계산용) |



### 하이퍼파라미터의 역할

| 파라미터 | 의미 | 설명 |
| --- | --- | --- |
| **C** | 규제 매개변수 | 마진 위반을 얼마나 허용할지 조절 (크면 과적합, 작으면 일반화) |
| **gamma (γ)** | RBF 커널 폭의 역수 | 작을수록 넓은 영역을, 클수록 좁은 영역을 의미 |
| **nu (ν)** | 허용 오차 비율 | SVC/SVR에서 마진 위반 비율 제어 |

---

### 커널 트릭 (Kernel Trick)

- **핵심 아이디어 :** 원래 선형으로 분리 불가능한 데이터를 **고차원 공간으로 변환해 선형 분리가 가능하도록 만드는 것**
    

| 커널 종류 | 설명 |
| --- | --- |
| **Linear** | 원본 공간에서 선형 분리 |
| **Polynomial** | 다항식 형태로 고차원 매핑 |
| **RBF (Radial Basis Function)** | 가우시안 분포 기반, 비선형 데이터에 효과적, 중심 기반 거리 계산 |
| **Sigmoid** | 로지스틱 함수 형태, 뉴런 활성화 함수와 유사 |

### One-Class SVM (비지도학습)

- **정상 데이터만 학습** → 이상치 탐지용(경계를 만들어서)
- 데이터의 **분포(공분산 등)를 기준으로 경계(타원형)를 형성**
- 경계 밖에 있는 데이터 → 이상치로 판단
- 오분류 줄이고 모델 신뢰도 향상
- 모델 분석 시 다음을 통해 영향도 확인 가능:
    - **SHARP :** 각 데이터가 예측에 미친 영향
    - **민감도 분석 / 영향점 분석** : 특정 데이터 제거 시 결과 변화를 관찰

## 정리

**1.** SVM은 데이터를 가장 넓은 여백으로 나누는 **최적의 초평면(Optimal Hyperplane)**을 찾는 지도학습 모델
- SVM은 데이터를 분류할 때, 두 클래스 사이에  **가장 넓은 여백(margin)**을 가진 **직선 또는 평면(초평면)**을 찾고, 이 여백이 넓을수록 새로운 데이터에 대해 **더 안정적인 예측 가능**
- ex) 고양이 vs 강아지를 구분할 때, 두 그룹 사이에 최대한 간격을 두고 선을 긋는 것

**2.** OneClassSVM 은 정상 데이터만 학습해 이상치를 탐지하는 **비지도학습 모델**
- OneClassSVM은 **이상치 탐지용 모델**
- 정상적인 데이터만 학습하고, 그 경계 밖에 있는 데이터를 **이상치(Outlier)**로 판단
- ex) 신용카드 거래 중 정상적인 패턴만 학습해서, 이상한 거래를 탐지하는 데 사용

**3.** 마진, 커널, 규제(C, γ, ν) 등을 조절해 모델의 정확도와 일반화 성능을 향상 
- SVM 하이퍼파라미터 튜닝에 대한 설명

| 요소 | 설명 | 효과 |
| --- | --- | --- |
| **Margin** | 두 클래스 사이의 여백 | 넓을수록 일반화 성능 향상 |
| **Kernel** | 데이터를 고차원으로 변환 | 선형으로 나눌 수 없는 데이터를 분리 가능 |
| **C** | 규제 강도 | 작을수록 마진을 넓게, 클수록 오차를 줄임 |
| **γ (gamma)** | RBF 커널의 폭 조절 | 작으면 넓은 영역, 크면 좁은 영역에 민감 |
| **ν (nu)** | OneClassSVM의 이상치 허용 비율 | 얼마나 이상치를 허용할지 조절 |


### 요약하면

이 모델들의 성능은 마진, 커널, 규제 같은 설정을 조절하면서 더 좋아지게 할 수 있어"
