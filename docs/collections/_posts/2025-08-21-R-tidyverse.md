## 데이터 분석 기초 정리

데이터 분석과 머신러닝, 딥러닝의 기반에는 **선형대수와 통계학**이 있습니다.  
R은 이러한 수학적 개념을 실제 데이터 처리와 모델링에 연결해주는 강력한 도구입니다.  
이번 정리에서는 벡터·행렬 연산, 통계 기본 개념, 전처리, 그리고 tidyverse 활용까지 핵심 내용을 다룹니다.

---

## 1. 벡터와 행렬 연산

### 벡터 (Vector)
- **내적(dot product)**: 두 벡터의 크기와 방향을 고려해 하나의 값으로 표현  
  $$\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos(\theta)$$
- 직교하는 벡터의 내적은 0 → 상관관계 없음

### 행렬 (Matrix)
- **행렬곱(matrix multiplication)**: 일반 곱셈과 달리 교환법칙이 성립하지 않음  
  예: A(2×3), B(3×4) → A×B는 가능하지만 B×A는 불가능
- **요소별 연산(Hadamard product)**: 같은 위치의 원소끼리 곱셈  
  - 가중치 부여, 마스킹(masking)에 자주 사용

### 고유값 분해 (Eigen Decomposition)
- 정방행렬이면서 대칭행렬에 적용
- `eigen()` 함수로 고유값과 고유벡터 계산
- **고유값**: 데이터의 분산 크기  
- **고유벡터**: 데이터가 퍼지는 방향 (서로 직교)
- 수치적으로 내적값이 `e-16` 같은 작은 값이 나오면 → 부동소수점 오차, 사실상 0으로 간주

👉 고유벡터를 이용해 데이터를 직교하는 축으로 변환하면 **다중공선성(multicollinearity)** 문제를 줄일 수 있음

### 특이값 분해 (SVD: Singular Value Decomposition)
- 비정방행렬에도 적용 가능
- $$A = U \Sigma V^T$$ 형태로 분해
- 가운데 Σ(시그마)는 고유값과 유사한 의미
- 추천 시스템, 텍스트 분석, 차원 축소(PCA) 등에 활용

## 2. 통계 기본 개념

| 항목 | 설명 |
| --- | --- |
| 합계 (Sum) | 전체 값의 합 |
| 평균 (Mean) | 값들의 평균 |
| 중위수 (Median) | 이상치에 덜 민감한 중심값 |
| 분산 (Variance) | 값들의 흩어짐 정도 |
| 표준편차 (SD) | 분산의 제곱근 |
| 표준오차 (SE) | 표본 평균의 오차 추정치 |
| 변동계수 (CV) | 표준편차 ÷ 평균 |

- **분산**: 같은 평균이라도 값이 얼마나 퍼져 있는지 확인  
- **표준편차**: 분산에 루트를 씌운 값  
- **표준오차(SE)**: 
  $$SE = \frac{SD}{\sqrt{n}}$$  
  표본 수가 많아질수록 SE ↓ → 모집단 평균에 가까워짐
- **신뢰구간(Confidence Interval)**: 
  $$\text{평균} \pm 1.96 \times SE$$ (95% 신뢰구간)

👉 키와 몸무게처럼 단위가 다른 변수는 **변동계수(CV)**로 비교해야 함

## 3. 데이터 전처리 (Pre-processing)

데이터는 원천 상태 그대로는 분석에 적합하지 않음  
따라서 **결측치 처리, 이상치 제거, 범주화, 정규화**가 필수

### 3-1. 결측치 처리 (Missing Values)
- `NA`: 값이 입력되지 않은 경우  
- `na.omit`: 행 단위 삭제 (열 삭제는 변수 손실 위험)  
- 대체 방법: 평균, 0, KNN 기반 대체  
  - KNN: 유사한 데이터의 평균으로 대체 → 가장 정교한 방식

### 3-2. 이상치 처리 (Outliers)
- **IQR (Interquartile Range)** 활용  
  $$IQR = Q3 - Q1$$  
  - 하한: Q1 - 1.5 × IQR  
  - 상한: Q3 + 1.5 × IQR  
  - 범위를 벗어나면 이상치로 간주  
- Boxplot으로 시각화 후 제거 가능

### 3-3. 범주화 (Categorization)
- **정량적 데이터**: 수치형  
- **정성적 데이터**: 범주형  
- 연속형 데이터도 구간 범주화 → 복잡성 감소, 모델 단순화  
- **One-hot Encoding**: 범주형 데이터를 0/1로 변환 → 딥러닝 필수

### 3-4. 정규화 (Normalization)

| 방법 | 설명 |
| --- | --- |
| Min-Max 정규화 | 모든 값을 0~1 범위로 변환 |
| Z-score 표준화 | 평균 0, 표준편차 1로 변환 |
| Robust 정규화 | 중위수 기준, IQR로 나눔 |
| L2 정규화 | 벡터 크기로 나눠 방향만 남김 |
| L1 정규화 | 절대값 합으로 나눠 일부 변수 0 처리 |

👉 정규화를 통해 변수 간 스케일 차이를 제거하고 모델 학습 안정화

## 4. R과 Tidyverse 활용

**Tidyverse**는 현대 데이터 과학을 위한 R 패키지 모음

- **tibble**: 개선된 데이터 프레임  
- **magrittr**: `%>%` 파이프 연산자  
- **dplyr**: 데이터 변환 (select, filter, mutate, arrange, summarize, group_by 등)  
- **tidyr**: 데이터 구조 변환 (long ↔ wide)  
- **readr**: CSV 등 데이터 불러오기  
- **stringr**: 문자열 처리  
- **forcats**: 범주형 데이터 처리  
- **purrr**: 함수형 프로그래밍(map, filter)  
- **lubridate**: 날짜·시간 처리  
- **ggplot2**: 시각화  
- **dbplyr**: 데이터베이스 연결

👉 `dplyr`은 데이터 프레임을 다루는 핵심 패키지, `dtplyr`은 대용량 데이터 처리에 최적화

## 정리

- **선형대수**: 벡터 내적, 행렬곱, Hadamard 연산, 고유값 분해, SVD  
- **통계학**: 평균·중위수·분산·표준편차·표준오차·변동계수, 점추정·구간추정  
- **전처리**: 결측치, 이상치, 범주화, 정규화  
- **R 활용**: tidyverse 패키지로 데이터 처리·시각화·모델링

👉 데이터 분석의 정확도와 모델 성능은 **수학적 이해(선형대수·통계) + 전처리 + R 활용 능력**에 달려 있음
