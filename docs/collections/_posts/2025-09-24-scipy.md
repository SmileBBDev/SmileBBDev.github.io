## Scipy와 수치해석

**"Scipy는 수학·통계를 컴퓨터가 계산할 수 있게 구현해주는 도구이고, 수치해석은 그 수학 문제를 근사적으로 풀 수 있도록 공식화한 방법"**

### 1. 수치해석이란?

- **정의**: 수학적인 문제를 실제로 계산(산술 연산)해서 풀 수 있도록 공식화하는 방법 <br>
(수학 문제를 컴퓨터로 풀 수 있게 수치로 바꾸는 기술)
- **이유**: 수학적으로는 연속적(미분, 적분, 삼각함수 등)인데 → 컴퓨터는 이산적(0,1)이라 그대로 계산 불가. 따라서 **근사적으로 수치 해법(연산 기법)** 으로 문제를 푸는 것

### 🔬 수학적 모델링 - 대표적인 기법(테일러/오일러)

- **테일러 급수**: 복잡한 함수를 다항식으로 근사  (ex. 삼각함수: (sin, cos), exp 함수)
- **오일러 정리**: 삼각함수를 지수 함수로 표현 → 급수로 풀 수 있음 (계산을 단순화)
- **인실리코 환경**: 장기나 약물 작용을 수식으로 모델링해서 시뮬레이션

👉 **머리로 푸는 수학 문제를 컴퓨터가 이해할 수 있게 바꿔서 풀도록 하는 과정**

### 2. Scipy의 역할

- **Numpy 기반** 라이브러리 → 수학·통계·과학계산 알고리즘이 모여 있음
- 수치해석* 툴박스(*수치해석 : 컴퓨터가 풀 수 있게 바꾼 수학들)
- 주요 기능:
    - **과학계산**: FFT(푸리에 변환), Random(난수), linalg(선형대수)
    - **통계**: 평균, 상관계수, 분포 함수
    - **최적화**: 최솟값, 최댓값 찾기, 경사하강법
    - **보간(interpolation)**: 없는 데이터 추정하기

### 3. 주요 기능과 개념

- 보간, 선형대수, 최적화, 확률/통계, 미적분, 푸리에변환, 이미지처리

### (1) 보간법 (Interpolation)

- **보간법**: 데이터가 없는 구간을 예측해서 채워줌
    - 선형 보간: 직선으로 연결
    - 스플라인: 곡선으로 부드럽게 연결
    - 예) (1,2), (3,6) 두 점이 있으면 → 그 사이의 (2, ?) 값을 예측

### (2) 선형대수(linalg)와 미적분 (Differentials, Integration)

- 벡터·행렬 계산 (회전, 확대/축소, 이동 등)
- **회전 행렬**: cos, sin을 이용해 좌표 회전
- **Scaling**: 축 방향으로 늘리거나 줄이기
- **미분/적분**: 함수 변화율 계산
    - 평균변화율 → 순간변화율 → 도함수
    - 적분은 면적 계산(누적효과, 전체 합)
    - 활용 : 기울기가 0인 지점 = 극값 (최댓값, 최솟값 판별 가능)
- 예) 회전행렬: 머신러닝, 이미지 처리, 데이터 압축(PCA*) 등에서 필수
    
    $$
    \begin{bmatrix}
    cosθ & -sinθ \\
    sinθ & cosθ
    \end{bmatrix}
    $$
    
&nbsp;&nbsp; ***PCA와 신호 처리**
- **PCA (주성분 분석)**: 데이터의 주요 방향(축)을 찾아 차원 축소
    - 공분산 → 고유값 분해 → 주성분 추출
- **신호 = 파동**: 모든 소리는 사인/코사인으로 표현 가능
- **FFT(푸리에 변환)**: 시간 → 주파수로 변환해서 노이즈 제거, 엣지 추출
- **필터링**:
    - 저주파 필터: 부드러운 정보만 남김
    - 고주파 필터: 엣지 강조, 노이즈 제거


### (3) 최적화(Optimization)와 머신러닝

- 최적화 : 어떤 함수의 최소값/최대값 찾기
- **최적화 방법**:
    - 경사 하강법 (딥러닝 학습에 사용)
    - 최소 제곱법 (예측값과 실제값 차이 최소화 = 오차 최소화)
    - 뉴턴 방법 (빠른 수렴)
- **그래프**: U자 모양(포물선) → 가장 낮은 점 = 최적
- **모델 분류 기준**:
    1. 정보 기반
    2. 확률 기반
    3. 유사도 기반
    4. 오차 기반 (예측 오차 최소화)


### (4) 확률 분포와 Norm

- **Norm (P, Q, R)**: 거리나 크기 측정 방식
- **확률 함수들**:
    - `rvs`: 랜덤 샘플(난수 생성)
    - `pdf`: 확률 밀도 함수 (y값, 얼마나 자주 발생하는지)
    - `cdf`: 누적 확률 (왼쪽 면적 = 왼쪽부터 확률 합)
    - `ppf`: 분위수 (x값, 특정 확률에 해당하는 x값을 뜻함)
- 정규분포, t-분포 등 다양한 분포 제공

### (5) **푸리에 변환 (FFT)**

- **시간 영역 → 주파수 영역 변환**
- 모든 신호(소리, 영상)는 sin/cos 파동의 합으로 표현 가능
- 활용:
    - **노이즈 제거**: 불필요한 고주파/저주파 성분 제거
    - **이미지 처리**: 엣지(경계선) 추출, 흐림 제거

### (6) 이미지 전처리

- 이미지 데이터를 수학적으로 변환
- **FFT 활용**:
    - 노이즈 제거
    - 엣지 검출
    - 영역 강조
    - CNN 성능 향상 - 이미지에서 노이즈 제거 후 딥러닝 적용
