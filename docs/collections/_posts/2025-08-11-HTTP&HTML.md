## HTTP와 HTML: 데이터 전달과 표현

웹 프로그래밍은 **윈도우 기반(Window Base)** 환경에서 **웹 브라우저(Web Browser)**를 통해 진행됩니다.
즉, 사용자가 보는 화면과 상호작용하는 방식은 브라우저가 담당하며, 그 하부 구조는 여러 프로그래밍 패러다임으로 이루어져 있습니다.  

---

## 윈도우 기반 프로그래밍의 하부 구조

- **GUI Based Programming**  
  - 모니터에 화면을 출력하는 방식  
  - 그래픽 사용자 인터페이스를 통해 시각적으로 표현  

- **Event Based Programming**  
  - 마우스 클릭, 키보드 입력 등 이벤트 발생 시 **핸들러(handler)**가 호출  
  - 웹에서는 *event handler*, DB에서는 *프로시저*에서 예외 발생 시 rollback 처리  

- **Form Based Programming**  
  - 입력 박스, 출력 박스 등 폼 요소를 활용  
  - 예: `<div>`, `<table>`, `<textarea>`, `<button>`  

- **Tag Based Programming**  
  - 태그 중심의 텍스트 기반 프로그래밍  
  - HTML 태그를 통해 구조를 정의하고, 클래스 인스턴스처럼 동작  

---

## HTML, CSS, JavaScript

- **HTML (Hyper Text Markup Language)**  
  - 콘텐츠를 구조화하여 표현  
  - 텍스트 기반 코드가 **HTTP(Hyper Text Transport Protocol)**를 통해 전달  

- **CSS**  
  - 스타일을 정의하여 화면을 꾸밈  

- **JavaScript**  
  - 동적 동작을 구현하여 사용자와 상호작용  

👉 세 가지가 결합하여 **클라이언트 화면에 출력**됩니다.  

---

## Contents와 MIME Type

- **MIME Type**: 웹에서 데이터 표현 방식  
  - 동영상, 사운드, 이미지, 텍스트 등  
- 프로그래밍 언어에서는 *데이터 타입*, 웹에서는 *MIME Type*이라고 부름  

### 데이터 요청 방식
- **GET**: 데이터가 URL에 노출된 상태로 전달  
- **POST**: 데이터를 숨겨서 전달 (보안성 ↑)  

---

## 웹 서버와 웹 애플리케이션 서버

- **Web Application Server (동적 처리)**  
  - JSP 서버 (Tomcat, Java 기반)  
  - Node.js (JavaScript 기반, 경량 서버)  
  - Flask (Python 기반, 모델 서버 처리에 적합)  
  - Django (Python 기반, 대규모 프로젝트에 활용)  

- **Web Server (정적 처리)**  
  - Apache, IIS, Nginx  
  - 정적 정보 전달 담당  

👉 Django는 Nginx와 함께 사용되는 경우가 많으며, Flask는 모델 서버를 다루는 데 적합합니다.  

---

## HTML 태그와 속성

- **Tag Base Program**  
  - `<div> </div>`: 태그 사이에 실행할 코드 작성  
  - `<input>`: 시작 태그만 존재하는 경우도 있음  

- **id와 name 속성**  
  - **id**: 브라우저에서 사용하는 이름, 고유해야 함 (중복 불가)  
  - **name**: 서버에서 사용하는 이름 (데이터 전달 시 사용)  

- **Attribute (속성)**  
  - 태그에 여러 타입을 지정하는 방식  
  - 예: `<input type="text" id="username" name="user">`  

---

## 이벤트 처리 흐름

- 모든 이벤트는 **윈도우(Window)**가 관리  
- 이벤트 발생 → 메시지 큐(Message Queue)에 적재 → 순서대로 처리 → 웹으로 전달  

👉 웹에서는 이벤트 핸들러가 이를 받아 동작을 수행합니다.  

---

## 정리

- **HTTP**: 데이터 전달 프로토콜  
- **HTML**: 데이터 표현 언어  
- **웹 프로그래밍**은 GUI, 이벤트, 폼, 태그 기반 구조로 이루어짐  
- **MIME Type**은 웹에서 데이터 표현을 정의하는 방식  
- **GET/POST** 요청으로 데이터 전달  
- **웹 서버 vs 웹 애플리케이션 서버**: 정적/동적 처리 구분  
- **HTML 태그**는 id, name, attribute를 통해 브라우저와 서버에서 각각 활용
