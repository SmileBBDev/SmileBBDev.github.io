## 1. Eager Mode vs Graph Mode

### TensorFlow와 PyTorch 이해하기
### TensorFlow
- **Eager Mode**: 연산이 즉시 실행됨 → 직관적, 디버깅에 유리  
- **Graph Mode (@tf.function)**: 코드를 그래프 형태로 컴파일 후 실행 → GPU 최적화, **속도 빠름**  
- **실무/배포**에서는 Graph Mode가 주로 사용됨  

### PyTorch
- 기본이 **Eager Mode(동적 계산 그래프)**  
- 연구·개발, 프로토타입 제작에 강점  

👉 **정리**: 개발 단계는 PyTorch, 배포 단계는 TensorFlow가 유리

## 2️. Tensor vs ndarray

| 항목 | Numpy ndarray | Tensor |
| --- | --- | --- |
| 연산 환경 | CPU 기반 | GPU + CPU 모두 지원 |
| 자동미분 | 불가 | 가능 (autograd) |
| 활용 | 수치연산, 시각화 | 딥러닝 최적화, 대규모 행렬연산 |
| 변환 | 기본 자료형 | `.numpy()`로 변환 가능 |

👉 **Tensor = 딥러닝 최적화된 자료형** (GPU, 자동미분, 대규모 선형대수)

---

## 3️. 딥러닝은 왜 빅데이터가 필요한가?

- 신경망은 **행렬곱과 내적**을 반복하며 수많은 파라미터를 학습  
- 파라미터가 많을수록 충분한 데이터가 필요 → 과적합 방지  
- CNN/RNN 같은 구조는 복잡한 패턴을 학습하므로 더 많은 데이터 필요  

💡 **데이터가 많아야 특징을 제대로 학습한다.**  
하지만 학습 속도를 위해 데이터 양을 줄이고 정규화하는 노력도 중요

---

## 4️. End-to-End 모델

TensorFlow는  **데이터 전처리 → 모델 구성 → 학습 → 배포**까지   
모두 지원하는 **End-to-End 플랫폼**  

**강점)**
머신러닝 기반 모델(확률·통계·유사도)부터 딥러닝(CNN, RNN, FFNN)까지 구현 가능

---

## 5. FFNN의 핵심 구조

### 기본 연산
- **선형 변환 (행렬곱)**
  $$ z = Wx + b  $$
- **비선형 활성화 적용**
  $$ a = \sigma(z)  $$

👉 은닉층이 깊어질수록 더 추상적인 특징을 학습

---

## 6. CNN, RNN과 FFNN의 관계

- **CNN**: 이미지 특징 추출  
- **RNN**: 시계열 특징 추출  
- 최종 예측은 대부분 **FFNN(MLP)**로 연결해서 수행  

- CNN → FFNN  
- RNN → FFNN  

---

## 7. Activation Function (비선형성)

- **Sigmoid**: 0~1 범위, 이진분류에 사용  
- **Tanh**: -1~1 범위, 중앙화 → 학습 안정적  
- **ReLU**: 음수는 0, 양수는 그대로 → 빠르고 효율적  

⚠️ 문제점:  
- 값이 크면 **발산**  
- 값이 0 근처면 **기울기 소실**  

👉 해결책: **Batch Normalization** 같은 정규화 기법 사용

---

## 8. 손실 함수 (Loss Function)

- **Cross Entropy**: 분류 문제에 사용  

  $$ L = -\sum_i y_i \log(\hat{y}_i)  $$

  - 정답 확률이 1 → 비용 0  
  - 잘못 예측할수록 로그값 ↑ → 페널티 증가  

- **MSE (Mean Squared Error)**: 회귀 문제에 사용  

  $$ L = (\hat{y} - y)^2 $$

---

## 9. 학습 과정: Forward & Backpropagation

1. **순전파(Forward)**: 입력 → 은닉층 → 출력 → 손실 계산  
2. **역전파(Backprop)**: 손실을 기준으로 가중치 업데이트  

   $$  W \leftarrow W - \eta \frac{\partial L}{\partial W}  $$ 

⚠️ 깊은 네트워크에서는 **vanishing gradient 문제** 발생 → 기울기를 잘 전달하는 구조가 중요

---

## 10. Dense Layer (Fully Connected Layer)

- 출력 차원만 지정하면 내부적으로 입력 shape에 맞게 가중치 행렬 자동 생성  
- 예: `Dense(128)` → 출력 차원이 128인 행렬곱 구조  
- 사이킷런 MLP와 동일한 원리

---

## 11. TensorFlow vs PyTorch (실무 활용)

| 항목 | TensorFlow | PyTorch |
| --- | --- | --- |
| 실행 모드 | Graph Mode 최적화 | 기본 Eager Mode |
| 배포 | 강력한 생태계 (SavedModel, TPU/GPU 지원) | 상대적으로 약함 |
| 활용 | 실무·배포 | 연구·개발 |

👉 기업에서는 **TensorFlow**를 선호, 연구 단계에서는 **PyTorch**가 편리

---

## 전체 핵심 요약

- **TensorFlow**: Graph Mode, End-to-End, 배포 최적화  
- **PyTorch**: Eager Mode, 연구·개발에 적합  
- **딥러닝**: 빅데이터 필요, 행렬곱+비선형 변환 기반  
- **CNN/RNN**: 특징 추출기, 최종 예측은 FFNN 연결  
- **Cross Entropy + Backprop**: 가중치 학습의 핵심  
- **Batch Normalization**: 발산/기울기 소실 방지 

| 구분 | 모델(Model) | 프레임워크(Framework) |
|------|-------------|------------------------|
| 정의 | 신경망 구조 자체 (레이어, 가중치, 활성화 함수 등으로 정의된 학습 시스템) | 모델을 구현·학습·배포할 수 있도록 지원하는 라이브러리/도구 |
| 예시 | FFNN, CNN, RNN, Transformer | TensorFlow, PyTorch |
| 역할 | 데이터 입력 → 연산 → 출력 (수학적 구조) | 모델을 쉽게 만들고 학습시키며 GPU/CPU 최적화, 자동미분, 배포 지원 |
| 비유 | 건축 설계도 (아파트, 빌라 구조) | 건축 도구/장비 (크레인, 콘크리트 믹서기) |
| 사용 목적 | 학습 시스템의 구조를 정의 | 모델을 효율적으로 구현하고 실행 |


👉 정리하면 **모델은 설계도**, **프레임워크는 그 설계도를 구현하는 도구**
- 모델 = 건축 설계도 (예: 아파트 구조, 빌라 구조)
- 프레임워크 = 건축 도구/장비 (예: 크레인, 콘크리트 믹서기)
