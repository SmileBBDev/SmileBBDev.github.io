## 시각화와 탐색적 데이터 분석 (EDA)

데이터 분석의 첫걸음은 **데이터를 이해하는 것**  
그 이해를 돕는 가장 강력한 도구가 바로 **시각화(Visualization)**입니다.  
탐색적 데이터 분석(Exploratory Data Analysis, EDA)은 데이터를 요약하고 시각화하여 패턴을 발견하고, 모델링 방향을 잡는 과정입니다.

---

## 시각화 목적

1. **비교 (Comparison)**  
   - 변수 간 차이, 그룹 간 차이를 직관적으로 확인  
   - 예: 그룹별 평균 비교, 막대그래프

2. **구성 (Composition)**  
   - 전체 중 각 요소가 차지하는 비율 확인  
   - 예: 원형 그래프, 누적 막대그래프

3. **분포 (Distribution)**  
   - 데이터가 어떻게 퍼져 있는지, 이상치가 있는지 확인  
   - 예: 히스토그램, 박스플롯

4. **관계 (Relationship)**  
   - 변수 간 상관관계 파악  
   - 예: 산점도, 상관계수 행렬

---

## 분석 전 알아야 할 개념

- **데이터프레임은 열 중심 구조**  
- **독립변수 간에는 상관관계가 없어야 함**  
- **독립변수와 종속변수 간에는 상관관계가 반드시 있어야 함**  
- **다중 공선성(multicollinearity)**: 독립변수 간 상관관계가 높을 때 발생  
- **해결 방법**: 주성분 분석(PCA), 고유값 분해

---

## 주성분 분석 (PCA)

- **목적**: 고차원 데이터를 저차원으로 축약하여 시각화 및 분석 용이성 확보  
- **방법**:  
  - 고유값(Eigenvalue): 각 주성분이 설명하는 분산의 크기  
  - 고유벡터(Eigenvector): 여러 변수의 조합으로 만들어진 새로운 축  
  - 내적을 통해 고유값 분해 수행  
- **결과**: 2~3차원으로 축소된 데이터 시각화 가능 → 데이터 패턴을 직관적으로 확인


## 데이터 요약 방법

1. **차원 축소 (PCA 등)**  
   - 많은 변수를 요약해 시각화  
2. **도수분포표 / 요약 통계**  
   - `summarize()` 함수로 평균, 중앙값, 범위 등 요약 후 시각화

## R 기본 시각화 함수

| 함수 | 설명 |
| --- | --- |
| `barplot()` | 범주별 개수 시각화 |
| `stem()` | 줄기-잎 그림 |
| `plot()` | 산점도, 데이터 분산 확인 |
| `boxplot()` | 이상치 탐지, 사분위수 시각화 |
| `hist()` | 히스토그램, 데이터 분포 확인 |
| `qqnorm()` | 정규성 확인 |
| `pairs()` | 변수 간 관계 시각화 |
| `curve()` | 함수 형태 시각화 |


## 보조 시각화 함수

- `title()`, `lines()`, `points()`, `abline()`  
- `text()`, `segments()`, `polygon()`  
- `legend()`, `axis()`, `box()`  

👉 그래프에 설명, 축, 범례, 선, 면 등을 추가해 시각적 정보 강화

---

## 차원 확장 표현 방법

- **색상(color)**, **모양(shape)**, **선 종류(lineType)** 등을 활용해 고차원 정보를 시각화  
- **범례(legend)**를 통해 시각적 요소의 의미 설명


## ggplot2 구성요소

| 구성 요소 | 설명 |
| --- | --- |
| **Data** | 시각화할 데이터 |
| **Function** | `qplot()`, `ggplot()`, `ggsave()` |
| **Coordinates** | 좌표계 설정 (데카르트, 원통형 등) |
| **Mapping** | 미적 요소 매핑 (color, shape 등) |
| **Geometries** | `geom_bar`, `geom_boxplot` 등 그래프 유형 |
| **Scales** | 색상, 크기 등 시각적 요소의 범위 조절 |
| **Facets** | 화면 분할 (그룹별 시각화) |
| **Themes** | 색상, 폰트, 배경 등 스타일 설정 |

---

## 정리

- **EDA(탐색적 데이터 분석)**은 데이터를 요약하고 시각화하여 패턴을 발견하는 과정  
- **시각화 목적**: 비교, 구성, 분포, 관계  
- **PCA**를 통해 다중 공선성을 해결하고 고차원 데이터를 저차원으로 축약  
- **R 기본 함수와 ggplot2**는 데이터 시각화의 핵심 도구  

👉 데이터 분석의 출발점은 **시각화와 탐색적 분석**  
데이터를 눈으로 확인하고 이해하는 과정이 있어야, 그 다음 단계인 모델링과 예측이 의미를 갖게 된다.
