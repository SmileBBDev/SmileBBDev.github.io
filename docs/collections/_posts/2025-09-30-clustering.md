## 머신러닝의 두 가지 큰 흐름

### 지도학습 (Supervised Learning)

- **정답(종속변수)**이 있는 데이터를 기반으로 학습
- 목표: 입력 → 정답 예측
- 예시:
    - **KNN**: 새로운 데이터가 들어오면, 주변에 있는 데이터들과 비교해서 가장 가까운 애들의 정답을 보고 예측
    - **기계 고장 예측**: 소음 데이터를 기반으로 "언제 고장날지"를 예측 → 정답이 있으므로 지도학습

---

### 비지도학습 (Unsupervised Learning)

- **정답 없음**, 데이터의 패턴이나 구조를 스스로 찾아냄
- 목표: 데이터끼리 비슷한 것끼리 묶기
- 예시:
    - **Clustering (군집분석)**: 비슷한 데이터끼리 그룹화(비슷한 질문끼리 묶어서 챗봇에 전달)
    - **챗봇 질문 분류**: 질문을 클러스터링해서 어떤 챗봇으로 보낼지 결정

---

## 군집(Clustering)이란?

- 비지도학습의 대표적인 방법
- 종속변수가(정답이) 없고, 데이터의 **유사성**을 기준으로 그룹을 나눔
- 예) 마트 고객을 구매 패턴에 따라 VIP, 일반, 저가형으로 나누는 것



## Clustering 알고리즘들

### K-Means

- 핵심 : 중심점(k개)을 정해서, 가까운 애들끼리 모이게 하자!
- 작동방식
    - **k개의 중심점**을 임의로 정하고
    - 모든 데이터를 가장 가까운 중심점에 할당
    - 중심점 → 그룹 → 중심 재계산 → 반복
    - 다시 데이터들을 가까운 중심점에 재할당
    - 중심점이 더 이상 안 움직이면 종료 
- 특징
    - 거리 기반이라 **구형군집**에 적합
    - k값(군집 수)을 미리 정해야 함
    - 속도 빠름, 직관적, 구현 쉬움
    - 이상치에 **민감**
- 비유 : 친구들끼리 모임 장소를 정할 때, 각자 집에서 가장 가까운 카페를 선택하고, 그 카페로 모이는 방식

### DBSCAN

- DBSCAN(Density-Based Spatial Clustering of Applications with Noise)
- 핵심 : 데이터가 많이 몰려있는 곳을 군집으로 보고, 떨어진 애들은 노이즈로 처리하자!
- 작동방식 
    1. *반경 ε 안에 최소한의 점(MinPts)**이 있으면 → 핵심점
    2. 핵심점 주변의 점들을 군집에 포함
    3. 연결된 점들을 계속 확장
    4. 군집에 속하지 않는 점은 **노이즈(이상치)**로 간주
- 특징
    - k값 필요 없음
    - **노이즈 제거**, **이상치 탐지**에 강함
    - **밀도 기반** 클러스터링 → 복잡도 형태 잘 잡음
    - 복잡한 형태의 데이터 잘 처리
    - 핵심 포인트 주변에 데이터가 충분히 있으면 → 클러스터 형성
- 비유 : 사람들이 모여 있는 곳을 행사장으로 보면, 혼자 떨어져 있는 사람은 행사에 참여하지 않은 것으로 보는 방식!



## KNN (K-Nearest Neighbors)

- **지도학습 알고리즘**
- 새로운 데이터가 들어오면, 기존 데이터 중에서 **가장 가까운 k개**를 찾아서 다수결로 예측
- 특징:
    - 학습 단계 없음 (모든 데이터를 저장해놓고 비교)
    - 예측할 때 시간이 오래 걸림
    - 거리 계산 방식: 유클리디안 거리, 맨해튼 거리 등


## 거리 계산 & 검색 구조

### Ball Tree

- 데이터를 **구 형태로 묶어서** 거리 계산
- 빠른 근사 검색 가능
- 이진 트리 아님

### KD Tree

- 데이터를 **초평면 기준으로 나눠서** 저장
- 빠른 검색 가능
- 고차원 데이터에 적합

### Brute Force

- 모든 데이터와 거리 계산 → 정확하지만 느림

### ANN (Approximate Nearest Neighbor)

- 근사적으로 가장 가까운 이웃을 빠르게 찾음
- 속도 빠름, 정확도 약간 낮을 수 있음



## Clustering의 활용 예

- **압축**: 중심값 기준으로 데이터를 요약 → 저장 공간 절약
- **이상탐지**: 어떤 그룹에도 속하지 않는 데이터 → 이상치로 판단
- **전처리**: 클러스터링 후 그룹별로 다른 모델 적용 가능

## 핵심 요약

### 전체 요약

| 개념 | 설명 | 예시 |
| --- | --- | --- |
| 지도학습 | 정답 있음 | KNN, 기계 고장 예측 |
| 비지도학습 | 정답 없음 | Clustering, 챗봇 질문 분류 |
| K-Means | 거리 기반 클러스터링 | 중심 재계산 반복 |
| DBSCAN | 밀도 기반 클러스터링 | 노이즈 제거, 이상탐지 |
| KNN | 가까운 이웃 기반 예측 | 거리 계산 후 다수결 |
| Ball Tree / KD Tree | 빠른 거리 계산 구조 | 대량 데이터 처리 |
| Brute / ANN | 거리 계산 방식 | 정확도 vs 속도 |

### K-Means vs DBSCAN vs KNN 비교 요약

| 항목             | K-Means                     | DBSCAN                          | KNN                                      |
|------------------|-----------------------------|----------------------------------|-------------------------------------------|
| 알고리즘 유형     | 군집화 (Clustering)         | 군집화 (Clustering)             | 분류 (Classification) / 회귀 (Regression) |
| 군집 수 (K)       | 필요함                      | 필요 없음                        | 필요 없음                                  |
| 데이터 분포 가정  | 원형/구형에 적합             | 밀도 기반, 임의의 모양 가능      | 없음 (거리 기반)                          |
| 이상치 처리       | 이상치에 민감                | 노이즈로 분리 가능                | 이상치에 따라 분류 결과 왜곡 가능         |
| 속도             | 빠름 (대규모 데이터에 효율적) | 느릴 수 있음 (밀도 계산)         | 예측 시 느림 (거리 계산 필요)             |
| 주요 파라미터     | K                           | ε(이웃 반경), MinPts(최소 이웃 수) | K(최근접 이웃 수), 거리 척도(Metric)       |
| 사용 목적         | 데이터 세분화 / 클러스터링   | 잡음 포함 데이터 군집화           | 새로운 데이터 분류 / 예측                 |

> ### point!  
#### K-Means, DBSCAN은 비지도학습 → 군집화  
#### KNN은 지도학습 → 분류/회귀
