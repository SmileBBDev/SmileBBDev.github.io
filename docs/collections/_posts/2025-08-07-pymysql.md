## PyMySQL과 네트워크 기본 개념 정리

파이썬에서 **PyMySQL** 패키지를 사용하면 데이터베이스에 직접 접속하여 **CRUD(Create, Read, Update, Delete)** 작업을 수행할 수 있습니다.  
이를 이해하기 위해서는 먼저 **네트워크 기본 개념**과 **DB 접속 구조**를 알아야 합니다.  

---

## 네트워크 기본 개념

### 🏠 Local Network 구성
- **Switch**: 여러 장비를 연결해주는 장치  
- **Gateway (Router)**: 외부 네트워크와 연결해주는 출입구 역할  
- **IP 주소 확인**: `ipconfig` 명령어로 확인 가능  

### 🏷️ IP 주소 구조
- 예시: `192.168.41.XX`  
- **IPv4**: 4개의 옥텟(0~255)로 구성 → 총 32비트  
- **서브넷 마스크**: 네트워크 범위 지정  
  - `255.255.255.0` → 256개 주소 가능  
  - `255.255.255.128` → 128개 주소 가능  


---

### IP 주소 종류

| 종류 | 설명 |
| --- | --- |
| 사설 IP | 내부 네트워크용 (예: 192.168.x.x) |
| 공인 IP | 인터넷에 직접 연결되는 주소 |


### NAT (Network Address Translation)
- **역할**: 사설 IP ↔ 공인 IP 변환  
- **동작 시점**: 로컬 네트워크에서 외부 인터넷으로 나갈 때  
- **장점**:  
  - IP 주소 절약  
  - 보안 강화  

👉 집에서 작업 시 사설 IP만으로는 접속 불가 → 라우터에서 NAT를 통해 공인 IP로 변환해야 가능  


### DNS (Domain Name System)
- **도메인 이름**: 사람이 기억하기 쉬운 주소  
- **DNS 역할**: 도메인 → IP 주소로 변환  
- **작동 흐름**:  
  1. 사용자가 `www.example.com` 입력  
  2. Gateway(라우터)를 통해 외부로 요청 전송  
  3. DNS 서버에 도메인 이름 질의  
  4. DNS 서버가 해당 도메인의 IP 주소 반환  
  5. IP 주소를 통해 목적지 서버 접속  
  6. 응답을 받아 사용자 화면에 출력  

👉 목적지에 도달하지 못하면 패킷은 소멸됨.

## 데이터베이스 접속 방식

| 도구 | 특징 |
| --- | --- |
| **HeidiSQL** | 관리용 GUI 프로그램 → 모든 DB 접속 가능 |
| **PyMySQL** | 응용 프로그램에서 사용 → 특정 DB에 직접 접속 지정 필요 |

### PyMySQL 접속 시 필요한 정보
- IP 주소 (서버 위치)  
- Port 번호 (기본: 3306)  
- Database 이름  
- 사용자 ID  
- 비밀번호  


## PyMySQL 연결 구조

### 🔗 Connection 객체
- **역할**: DB와 연결 관리  
- **주요 메서드**:  
  - `commit()` : 트랜잭션 확정  
  - `rollback()` : 트랜잭션 취소  
  - `cursor()` : 커서 객체 생성  

### 🖱️ Cursor 객체
- **역할**: SQL 명령 실행 및 결과 처리  
- **종류**: 서버 커서 / 로컬 커서  
- **주요 메서드**:  
  - `execute()` : SQL 실행  
  - `fetchone()` : 단일 행 반환  
  - `fetchmany(n)` : n개의 행 반환  
  - `fetchall()` : 전체 행 반환  

### ⏺️ Record & Record Set
- **Record**: DB의 단일 행  
- **Record Set**: 여러 Record로 구성된 결과 집합  

---

## 데이터 타입과 변환
`cursor.description` → 컬럼 구조 및 타입 확인 가능  
- DB는 메모리 효율을 위해 다양한 데이터 타입 사용  
- 커서가 DB 타입을 언어에 맞게 변환  
- 결과 기본 반환: **튜플(수정 불가)**  
- 필요 시 **리스트**로 변환하여 수정 가능  
- **딕셔너리**로 받으면 검색에 유리  

## 요약 팁

| 상황 | 추천 반환 타입 |
| --- | --- |
| 검색이 많을 때 | `dict` |
| 전체 데이터 처리 | `tuple` |


---

## 이터레이터 동작
- 커서는 내부적으로 **이터레이터** 사용  
- `fetchall()` 호출 시 이터레이터는 마지막 위치로 이동  

## 트랜잭션 처리
- **Auto Commit ON**  
  - SQL 실행 즉시 반영  
  - 취소 불가 → 충돌 위험  
- **Auto Commit OFF**  
  - SQL 실행 후 `commit()` 호출 시 확정  
  - `rollback()`으로 취소 가능  


```sql
[Auto Commit ON]
     |
     |-- SQL 실행 → 즉시 반영
     |-- 취소 불가

[Auto Commit OFF]
     |
     |-- SQL 실행
     |-- commit
```

## 데이터베이스 연결 흐름도

```sql
+------------------+
|  Connection 객체 |
+------------------+
       |
       |-- commit()
       |-- rollback()
       |
       v
+------------------+
|   Cursor 객체    |
+------------------+
       |
       |-- execute(SQL)
       |-- fetchone()
       |-- fetchmany(n)
       |-- fetchall()
       |
       v
+------------------+
|   Record Set     |
+------------------+
       |
       |-- Record 1
       |-- Record 2
       |-- ...
       |
       v
+------------------+
|  데이터 타입 변환 |
+------------------+
       |-- Tuple (기본)
       |-- List (수정 가능)
       |-- Dict (검색 유리)
       |
       v
+------------------+
| cursor.description |
+------------------+
```

## 정리
- PyMySQL은 파이썬에서 DB에 직접 접속해 CRUD 작업을 수행할 수 있는 외부 패키지  
- DB 접속에는 **IP, Port, DB명, ID, Password**가 필요  
- Connection 객체와 Cursor 객체를 통해 SQL 실행 및 결과 처리  
- Record/Record Set 구조로 데이터를 반환하며, 튜플·리스트·딕셔너리로 변환 가능  
- Auto Commit 설정에 따라 트랜잭션 처리 방식이 달라짐
