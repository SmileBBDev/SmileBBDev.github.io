## 데이터 분석과 통계 & 전처리 개념 정리

데이터 분석과 머신러닝, 딥러닝의 핵심에는 **통계학과 선형대수학**이 자리 잡고 있습니다.  
행렬과 벡터 연산을 통해 데이터를 변환하고, 모집단과 표본을 이해하며, 모델을 자동화하는 과정은 모두 수학적 개념의 응용이라고 할 수 있습니다. 특히 **R**은 이러한 기반 위에서 통계 처리와 데이터 분석에 최적화된 언어로, **모델 생성과 자동화까지 폭넓게 활용**됩니다.

---

## 1. 데이터 전처리의 중요성
- **모델 성능의 70%는 전처리에서 결정됨**
- 데이터를 잘못 다루면 모델이 잘못된 결과를 도출
- 결측치 처리, 이상치 제거, 정규화 등은 필수



## 2. 모집단 vs 표본
- **모집단**: 전체 데이터 집합 (분석 불가능할 정도로 큼)
- **표본**: 모집단에서 추출한 일부 데이터
- 표본을 통해 모집단의 특성을 **추정**함

---

## 3. 기본 통계량

| 항목 | 설명 |
| --- | --- |
| 합계 (Sum) | 전체 값의 합 |
| 평균 (Mean) | 값들의 평균 |
| 분산 (Variance) | 값들의 흩어짐 정도 |
| 표준편차 (SD) | 분산의 제곱근 |
| 표준오차 (SE) | 표본 평균의 오차 추정치 |
| 변동계수 (CV) | 표준편차 ÷ 평균 |

---

## 4. 분산과 자유도
- 표본의 분산 계산 시 **n-1**로 나눔 → **자유도**
- 이유: 표본 평균을 기준으로 계산하므로 하나의 값은 자유롭게 선택할 수 없음
- **표준편차**는 분산의 제곱근


## 5. 표준오차 (Standard Error)
- 표본 평균의 **추정 오차**
- 계산:
  $$SE = \frac{SD}{\sqrt{n}}$$
- 표본 수가 많아질수록 SE는 작아짐 → 모집단 평균에 가까워짐


## 6. 점추정 vs 구간추정
- **점추정**: 하나의 값으로 모집단 추정 (불확실성 큼)
- **구간추정**: 일정 범위로 추정 → 신뢰구간 사용

  95% 신뢰구간 계산:
  $$\text{평균} \pm 1.96 \times SE$$


## 7. t분포와 f분포
- **t분포**: 표본 수가 적을 때 평균 비교에 사용
- **f분포**: 분산 비교에 사용 (예: 분산분석 ANOVA)

---

## 8. 변동계수 (Coefficient of Variation)
- 집단 간 **변화의 상대적 크기** 비교
- 계산:
  $$CV = \frac{SD}{Mean}$$
- 평균이 다른 집단 간 비교에 유용


## 9. 표준편차와 Z-점수 (Z-score)
- 공식: 
$$Z = \frac{X - \mu}{\sigma}$$
  - X: 데이터 값
  - μ: 평균
  - σ: 표준편차
- 의미: 평균에서 얼마나 떨어져 있는지를 표준편차 기준으로 나타냄
- 정규분포에서 활용:
  - Z = ±1 → 약 68% 데이터 포함
  - Z = ±2 → 약 95% 데이터 포함
  - Z = ±3 → 약 99.7% 데이터 포함
- 머신러닝/딥러닝에서 **데이터 정규화**를 위해 Z-score는 매우 중요

## 10. Feature Engineering 단계

### 10-1. ETL
- **Extract**: 데이터 수집  
- **Transform**: 데이터 정제 및 변환  
- **Load**: 분석 환경에 적재  

### 10-2. 데이터 클리닝
- **결측치 처리 (Missing Values)**  
  - 삭제: 행 단위 제거(열 제거는 변수 손실)
  - 대체: 평균, 0, KNN 기반 대체  
- **이상값 처리 (Outliers)**  
  - 중위수(Median): 이상치에 영향을 덜 받는 중심값  
  - IQR (Interquartile Range):
  $$IQR = Q3 - Q1$$  
    - 하한: Q1 - 1.5 × IQR  
    - 상한: Q3 + 1.5 × IQR  
    - 범위를 벗어나면 이상치  

### 10-3. 범주화 (Categorization)
- 정량적 데이터 vs 정성적 데이터  
- Factor 변수 변환, 구간 범주화  
- **One-hot Encoding**: 범주형 데이터를 0/1로 변환 → 딥러닝 필수  

### 10-4. 정규화 (Normalization)

| 방법 | 설명 |
| --- | --- |
| Min-Max 정규화 | 모든 값을 0~1 범위로 변환 |
| Z-score 표준화 | 평균 0, 표준편차 1로 변환 |
| Robust 정규화 | 중위수 기준, IQR로 나눔 |
| L2 정규화 | 벡터 크기로 나눠 방향만 남김 |

**정규화 목적**
- 변수 간 스케일 차이 제거
- 종속변수에 과도한 영향 방지
- 모델 학습 안정화

### 10-5. 시각화 (Visualization)

| 기법 | 설명 |
| --- | --- |
| Histogram | 데이터 분포 확인 |
| Boxplot | 이상치 탐지 |
| Scatter Plot | 변수 간 관계 시각화 |
| Heatmap | 상관관계 시각화 |
| Pairplot | 다변량 관계 탐색 |
| Bar/Pie Chart | 범주형 데이터 표현 |

## 11. 선형대수와 R을 활용한 데이터 분석

### 행렬곱과 내적
- 행렬곱은 일반 곱셈과 달리 **교환법칙이 성립하지 않음**  
  예: A(2x3), B(3x4) → A×B는 가능하지만 B×A는 불가능  
- 벡터 내적(dot product):  
  $$\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos(\theta)$$

### 벡터의 회전과 변환
- 회전 행렬을 곱하면 벡터의 방향이 바뀜  
- 예: 90도 회전 행렬 → (1,0) → (0,1)

### 차원 축소와 딥러닝
- PCA(주성분 분석), 오토인코더 → 특징 추출과 노이즈 제거  
- 데이터 차원을 줄여 모델 성능 향상

### 고유값 분해와 특이값 분해
- **고유값 분해(Eigenvalue Decomposition)**: 정방행렬에 적용, PCA 핵심  
- **특이값 분해(SVD)**: 모든 행렬에 적용 가능, 추천 시스템·텍스트 분석 활용  

### 상관계수 행렬 vs 공분산 행렬
- 상관계수 행렬: 변수 간 상대적 관계(−1 ~ +1)  
- 공분산 행렬: PCA와 차원 축소에 활용  

### 거리 값 행렬
- 데이터 간 거리(유클리드 거리 등) → 클러스터링, 시각화 활용

## 정리
- **통계학**: 모집단과 표본, 분산·표준편차·표준오차, 신뢰구간, t/f 분포, 변동계수  
- **데이터 전처리**: 결측치·이상치 처리, 범주화, 정규화, 시각화  
- **선형대수**: 행렬곱, 내적, PCA, SVD, 공분산·상관계수 행렬  
- **R 활용**: 데이터 처리(`dplyr`), 시각화(`ggplot2`), 모델링(`caret`), 자동화(`rmarkdown`)  

👉 결국, **데이터 분석의 정확도와 모델 성능은 통계적 이해와 전처리, 그리고 선형대수적 사고에 달려 있다**는 점을 기억!
