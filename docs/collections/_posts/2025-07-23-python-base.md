## 파이썬 기본 원리
### < 프로그래밍 언어의 역사와 흐름 >
프로그래밍을 하기 위해서 필요한 언어들이 존재
- assembly (어셈블리) : 가장 기초적인 저급 언어, 기계어와 거의 동일
- C → C++ → java → Python : 고급 언어로 발전하며 추상화 수준이 높아짐
- C언어는 고급 언어로 컴파일을 통해 기계어(2진수)로 변환함
  - `main()`함수가 진입점
  - 함수는 명령어 집합이고 추상화의 시작
  - 함수를 이용하여 프로그램을 구성
  - 변수는 직접 데이터를 담거나 주소를 담음(일반변수 vs 포인터 변수)

**컴파일**: 내가 짠 코드를 컴퓨터가 읽어 들이기 위해선 기계어로 변환하는 작업

- 기계어는 2진수로 되어 있고, 8비트의 자리를 이용해서 읽어들임.
- 1바이트 = 8비트 ex) 00000001, 00000011
- 1바이트 = 2의 8제곱. 즉, 256개의 데이터 표현이 가능

클래스에는 멤버변수, 멤버함수가 들어가 있고 동적 메모리 할당을 받음.

### < 메모리 구조 : Heap 과 Stack >  
우리가 사용하는 데이터는 엄청 거대하기 때문에
대량의 데이터를 처리하기 위해서 메모리를 **Heap과 Stack 영역**으로 나눠서 사용

- **Heap**  : 데이터가 어디에 있는지 위치만 알려줌, 데이터를 로딩
- **Stack** : 함수가 동작하면 주소를 넘겨 받아 함수가 필요로 하는 데이터 처리

| 영역 | 설명 |
| --- | --- |
| **Heap** | 동적 메모리 할당 영역, 대량의 외부 데이터를 저장 |
| **Stack** | 함수 실행 시 필요한 데이터 저장, 호출 순서에 따라 늘었다 줄었다 함 |

- 함수는 데이터를 처리할 때 Heap에 있는 데이터의 주소만 **stack**영역에 전달받아서 사용 <br> → Stack이 늘어났다가 줄어드는 원리로 동작

- stack에 직접 대량 데이터를 올리면 overflow 발생 가능
- 주소만 전달받아 필요한 순간에 Heap에서 데이터를 참조

  → ex) c언어에서 main 함수 안에 print(), read() 등의 함수를 실행하도록 작성


### < 변수와 포인터 >

1. 직접 데이터가 들어있는 변수 = 일반 변수
2. 데이터를 동적 메모리에 할당해 놓고, 주소를 알려주는 변수 = 포인터 변수

## 데이터 처리방법
프로그램은 데이터를 처리하는 것!

Data의 종류

문자, 숫자, 이미지, 동영상, 사운드 등등 존재

모든 데이터를 처리하려면 일단 메모리에 로딩이 되어야 함.

데이터는 모두 2진수로 바꿔줘야 함. → 인코딩 이라고 부름

**숫자** - 2진수로 만들려면… 2로 나누는 것

**문자** - 코드표가 존재, 숫자로 변환하기 위해서- ASCII(아스키코드 사용- 65=A, 97=a)

**이미지** - 사이즈에 따라 격자를 만들고, 픽셀(pixel) 단위로 나눠준 뒤, 1픽셀의 rgb 값과 매핑 후 데이터 처리

rgb는 각각 256으로 이뤄져 있고 → 이 숫자를 기반으로 이미지를 만들 수 있는 것

**동영상** - 동영상도 이미지와 마찬가지… 이미지 여러개를 겹친거 → 반복하여 처리하면 동영상 처리 가능

**사운드** - 음역대 높이에 따라서 숫자로 바꾼 후 매핑해서 처리(음성 처리 할 때 배울 예정)

⇒ 이렇게!!! 데이터를 처리하려면 모두 2진수로 변환되어 있어야 함.

그렇다면, 숫자 65랑 문자 A의 아스키코드랑 똑같은 2진수인데 구분을 어떻게 할까? 데이터 타입으로 구분!

C언어를 보면 int a = 12 이렇게 지정해 놓으면,

a라는 변수에 10을 집어넣을 건데 데이터 타입은 int라고 선언하게 됨.

그리고 a변수에는 주소가 들어있는데 주소는 1바이트마다 나눠져 있음

int는 4바이트

a는 주소의 시작 위치이고, 사이즈는 데이터 타입이 정해준다.

⇒ 앞 포스팅에서 보았 듯 컴퓨터가 알 수 있도록 주소 값으로 바꿔 주는 작업을 ‘컴파일 한다’ 라고 함.

이를 기반으로 만들어진 실행 파일의 확장자가 .exe 파일임.

이 과정들을 모두 인코딩이라고 함.

컴퓨터는 연산을 제일 잘하는 친구. 계산하는 애

이미지, 숫자, 문자, 동영상, 사운드 모두 이진수 연산의 대상임.

ex)

이미지에 10을 더해주면 이미지가 밝아지는것 - 픽셀값이 올라갔으니까
이미지에 10을 빼주면 이미지가 어두워지는것 - 픽셀이 어두워지니까

연산(+더하기, -빼기, *곱하기, /나누기)만 잘하면 AI정복도 가능함.

인코딩된걸 사람이 보려면 다시 디코딩 되어야 함.

앞으로 난 모델을 응용하는 사람이기 때문에 응용해서 도메인을 날릴 수 있는 데이터를 잘 처리하는 작업이 필요함.
메모리 로딩을 해야 돼 =모두 2진수로 메모리에 로딩 되어야 해
사람이 볼 때는 디코딩을 시켜야 해 - 문자, 숫자, 이미지로 화면에 보여 지도록
프린트 함수를 쓰게 되면 프린트 다음에 적힌 코드가 화면에 나오기만 하면 돼

## 파이썬 핵심 개념 요약

### 1. 변수와 메모리 구조
- 파이썬은 **데이터 타입을 명시하지 않아도** 변수 사용 가능 → **동적 타입 언어**
- 변수는 **값이 아닌 주소를 저장** → 값은 **Heap 메모리**에 저장되고, 변수는 그 주소를 참조
- 함수 실행 시 필요한 데이터는 **Stack 메모리**에 저장
- 모든 데이터는 **메모리에 올라가야** 처리 가능하며, 결국 **2진수로 변환**되어 연산
- 변수 초기화는 필수! 초기화하지 않으면 프로그램이 오류로 종료될 수 있음

### 2. 포인터 개념과 언어 비교
- C: `*` 기호로 포인터 변수와 일반 변수 구분
- Java: 포인터 개념을 일부 제거하고 클래스 중심으로 설계
- Python: **모든 변수는 포인터처럼 동작** → 일반 변수 개념 없음
- 포인터 변수는 주소를 가리키고, 그 주소 안에 또 다른 주소가 있을 수 있음

### 3. 변수의 목적
1. **계산(연산)**을 위해
2. **CRUD** (Create, Read, Update, Delete) 작업을 위해

### 4. 객체지향 프로그래밍 (OOP)
- 파이썬은 **객체지향 언어**이며, 모든 것이 객체임
- **클래스**는 데이터와 그 데이터를 처리하는 함수를 묶은 추상화된 구조
- 클래스는 객체를 만들기 위한 설계도
- 파이썬은 전역 변수와 함수도 허용하는 **유연한 객체지향 언어**

### 5. 파이썬의 특징

| 특징 | 설명 |
|------|------|
| High-level | 사람이 이해하기 쉬운 문법 |
| 범용 언어 | 다양한 분야에 사용 가능 |
| Interpreter | 해석기 기반 → 실행 시점에 번역 |
| Interactive | 대화형 실행 가능 (REPL) |
| Object-Oriented | 객체지향 프로그래밍 지원 |
| Scripting | 스크립트 언어로 빠른 개발 가능 |
| 확장자 | `.py` |

### 6. 컴파일 과정
- **렉싱(Lexing)**: 코드의 단어 단위 분석
- **파싱(Parsing)**: 문법 구조 분석
- **컴파일(Compile)**: 실행 가능한 바이트코드로 변환
- 파이썬은 바이트코드로 변환된 후 **가상머신(Python VM)**에서 실행됨
