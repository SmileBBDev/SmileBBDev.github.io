## ✅ 블로그 글에서 자주 쓰이는 패턴

제목(H2, H3) + 본문 + 코드블록/수식 조합

리스트로 핵심 정리

표로 비교 (예: AR, MA, ARIMA 특징 비교)

체크리스트 → TODO / 핵심 요약 표시할 때 좋음

인용문 → 정의/참고/경고 메시지 강조

## 📝 마크다운 글자 크기 정리

| 문법 | 제목 수준 | 용도 및 설명 |
|---------------|-----------|--------------|
| `#`           | **H1**    | 가장 큰 글씨. 일반적으로 페이지나 문서의 타이틀에 사용. 본문에서는 잘 사용하지 않음. |
| `##`          | **H2**    | 주요 섹션 제목. 본문 구조를 나눌 때 가장 많이 사용됨. |
| `###`         | **H3**    | 소제목. H2 아래의 하위 항목을 설명할 때 사용. |
| `####`        | **H4**    | 세부 단위 제목. 문서 정리를 더 세밀하게 하고 싶을 때 사용. |
| `#####`       | **H5**    | 잘 사용되진 않지만, 복잡한 문서에서 유용함. |
| `######`      | **H6**    | 가장 작은 제목. 거의 사용되지 않지만 필요 시 활용 가능. |


💡 **팁**:  
- 마크다운에서는 `#`의 개수가 많아질수록 글씨 크기가 작아진다.  
- 일반적인 문서에서는 H2 ~ H3(`##`와 `###`)만으로도 충분히 구조화할 수 있다.  
- 제목 아래에 본문을 작성할 때는 한 줄 띄우는 게 가독성에 좋다.

## 🖥️ 인라인 코드와 코드 블록 
인라인 코드:  `print("Hello World")`

```python
# 코드 블록 (언어를 지정하면 하이라이팅)
def add(a, b):
    return a + b
```

💡 **팁**  
- 인라인 코드는 백틱(`) 한 개로 감싸고,  
- 코드 블록은 백틱 세 개(```)로 감싸며, 언어를 지정하면 문법 강조 됨. (`python`, `html`, `js` 등).  
- 코드 블록은 들여쓰기나 줄바꿈이 유지돼서 가독성이 좋다.

## 🎯 Table(표) 작성법
표는 | 기호를 사용해서 열을 나누고, ---로 헤더와 내용을 구분한다.

📌 주의할 점
- 열 개수는 헤더와 내용이 반드시 일치
- :를 사용하면 정렬도 가능 
  - 왼쪽 정렬 ( `:---` )
  - 오른쪽 정렬( `---:` )
  - 가운데 정렬( `:---:` )


| 항목 | 설명 | 
| :---: | --- |
| A | 설명 | 
| B | 설명 |
