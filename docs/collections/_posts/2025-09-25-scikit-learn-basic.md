## Scikit-Learn
### Scikit-learn이란?

- **머신러닝 모델을 구현한 라이브러리** (넘파이, 판다스는 데이터 전처리용)
- **지도학습, 비지도학습, 준지도학습, 강화학습** 모두 지원
- **전처리 기능도 일부 포함**: 결측치 처리, 정규화, 범주화 등


### 머신러닝 학습 종류

| 종류 | 설명 |
| --- | --- |
| 지도학습 | 입력과 정답(라벨)이 모두 있음 |
| 비지도학습 | 라벨 없이 패턴만 찾음 |
| 준지도학습 | 일부 라벨만 있음 |
| 강화학습 | 실시간 선택과 보상 기반 학습 (scikit-learn은 지원 안 함) |

---

### Scikit-learn의 특징

- GPU 사용 ❌, 분산처리 ❌ → **CPU 기반 병렬 처리만 지원**
- `n_jobs` 옵션으로 **멀티코어 병렬 처리 가능**
- 대용량 데이터는 잘 안 다룸 → **중소규모 데이터에 적합**
- **매년 모델 추가/삭제** → 지속적인 개선
- 2.0 시대 이후로 **정확도와 해석력 향상**


### 차원 감소 (Dimensionality Reduction)

- 목적: **노이즈 제거**, **복잡성 감소**, **해석력 향상**
- 대표 기법: **PCA (주성분 분석)** → 이후 **PCRF** 등 발전


### 전처리와 파이프라인

- 전처리는 **데이터 분할 후에 해야 과적합 방지**
- 예: 이상치 제거, 정규화, 범주화 등
- 전처리를 여러 번 반복하게 되므로 → **Pipeline**으로 자동화
  - `Transformer` + `Estimator` 연결
  - 일방통행 구조로 처리

### 모델 구조

| 구성 요소 | 설명 |
| --- | --- |
| Estimator | 모델 생성기 (Regressor, Classifier, Cluster 등) |
| Transformer | 전처리기 (정규화, 결측치 처리 등) |
| Predictor | 예측 기능 포함 |

---

### 데이터 분할과 평가

- 일반적으로 **Train/Test = 7:3**
- 과적합 방지를 위해 **테스트 데이터는 학습에 포함되면 안 됨**
- **Cross Validation (CV)**: 데이터를 여러 조각으로 나눠서 학습/테스트 반복
    - 예: 10등분 → 9개 학습, 1개 테스트 → 정확도 향상

---

### 회귀 분석 (Regression)

- 통계학의 회귀와 다름 → **전제조건 없이 최소제곱법만 사용**
- 문제점: **과적합**
- 해결책: **규제(Regularization)**

### 규제 종류

| 규제 | 설명 |
| --- | --- |
| L1 (Lasso) | 절대값 기반 → 변수 선택 효과 |
| L2 (Ridge) | 제곱 기반 → 부드러운 제약 |
| ElasticNet | L1 + L2 혼합 |

- 규제는 손실함수에 더해져서 과적합을 막음
- 규제값은 줄일 수 없고, **모델이 손실을 최소화하려고 노력함**

---

### 대량 데이터용 모델

- `SGDRegressor`: **확률적 경사 하강법**으로 대량 데이터 처리
- `LogisticRegressionCV`: 자동으로 **학습/테스트 반복** + **파라미터 튜닝**

---

### GridSearchCV

- **파라미터 조합을 자동으로 테스트해서 최적값을 찾아줌**
    - Grid: 가능한 파라미터 값들
    - Search: 최적 조합 탐색
    - CV: 교차 검증으로 정확도 평가

---

## 라이브러리별 용도 정리
- **Numpy** = 기본 재료 (숫자, 배열 계산)
- **SciPy** = 요리 도구 (고급 수학/통계 알고리즘)
- **Scikit-learn** = 요리사 (도구와 재료를 활용해 머신러닝 모델을 "만들고" "훈련"하는 역할)

| 구분 | NumPy | SciPy | Scikit-learn |
| --- | --- | --- | --- |
| 역할 | 다차원 배열 연산(벡터, 행렬 계산) | 과학·수학 계산(최적화, 적분, 통계, 신호처리 등) | 머신러닝 알고리즘(분류, 회귀, 군집, 차원축소 등) |
| 기반 | C 기반 고속 수치 연산 | NumPy 기반 | NumPy + SciPy 기반 |
| 주요 기능 | 배열 연산, 선형대수, 브로드캐스팅 | 고급 수학 알고리즘, 희소 행렬, 최적화, 통계 | 머신러닝 모델 학습/평가, 데이터 전처리, 파이프라인 |
| 사용자 | 데이터 처리 입문자, 과학계산 기초 | 연구자, 공학/통계 계산 필요자 | 머신러닝 개발자, 데이터 과학자 |
| 관계 | 기본 연산 제공 | NumPy 확장 | NumPy + SciPy 활용해서 ML 구현 |

### 요약:

- **NumPy** = 숫자 계산의 뼈대
- **SciPy** = 수학 알고리즘 도구 모음
- **Scikit-learn** = 이 둘을 이용해서 머신러닝을 쉽게 쓸 수 있게 만든 라이브러리
