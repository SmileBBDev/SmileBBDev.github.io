## Numpy(넘파이)란?

- 넘파이는 파이썬에서 **과학적 계산**과 **수치 연산**을 빠르고 효율적으로 처리하기 위한 기초 라이브러리

- 다차원 배열(ndarray)을 중심으로 작동 → **리스트보다 빠르고 효율적**
- 수학/통계/선형대수 등 다양한 기능을 제공
- 많은 데이터 분석과 머신러닝 라이브러리들 제작의 기반
  - **데이터분석, 머신러닝, 이미지 처리** 등 거의 모든 분야에서 사용
  - 넘파이를 잘 힉히면 아래 예시의 고급 라이브러리도 쉽게 다를 수 있음
  예) Scipy(사이파이), Pandas, Scikit-learn, TensorFlow 등

## 넘파이 핵심 : ndarry(N차원 배열)
- ndarry는 넘파이의 가장 중요한 구조
- ndarry는 **다차원 배열 객체**
- ndarry를 이용하여 벡터/행렬/텐서 같은 수학구조를 쉽게 사용

| 구조 | 설명 | 예시 |
| --- | --- | --- |
| 1차원 | 벡터 | [1, 2, 3] |
| 2차원 | 행렬 | [[1, 2], [3, 4]] |
| 3차원 이상 | 텐서 | [[[1], [2]], [[3], [4]]] |

pandas에선 데이터프레임, 리스트 자료형 사용, 넘파이의 ndarray를 내부적으로 사용, 더 직관적이고 강력한 데이터 분석 기능 제공

## 넘파이 주요 특징
- **동질적 데이터**만 저장 가능 →  모든 요소가 같은 타입
- **연속적인 메모리 공간** 사용 →  빠른 연산 가능, 캐시 최적화
- **벡터화 연산** →  반복문 없이 빠르게 계산
- **Broadcasting** →  배열 크기가 달라도 자동으로 맞춰서 연산(계산)

## 넘파이에서 자주 쓰는 기능
- **수학/통계 함수** → 평균, 표준편차, 로그, 지수 등
- **선형대수** →  행렬 연산, 역행렬, 고유값
- **신호처리** →  푸리에변환(시간이나 공간에 대한 함수를 **시간 또는 공간 주파수** 성분으로 분해하는 변환)
- **난수생성** →  다양한 분포 기반의 난수
- **ufunc (universal function)** → 벡터화 연산을 지원하는 고속 함수들

### 📐 수학 함수

초월함수 - 지수 → exp / 로그 → log / 삼각 → sin, cos 등

초월함수는 다항식의 근(solution)으로 표현될 수 없는 함수이다.

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

a + b  # 요소별 덧셈
np.exp(a)  # 지수 함수
np.log(a)  # 로그 함수
np.sin(a)  # 삼각 함수

```

### 📊 통계 함수

평균, 분산, 표준편차, 상관계수 등

```python
np.mean(a)  # 평균
np.std(a)   # 표준편차
np.var(a)   # 분산
np.corrcoef(a, b)  # 상관계수
```

### 🧮 선형대수 (numpy.linalg)

행렬 연산, 역행렬, 고유값 등

```python
from numpy.linalg import inv, norm

matrix = np.array([[1, 2], [3, 4]])
inv(matrix)  # 역행렬
norm(matrix)  # 벡터의 크기
```

### 🔊 신호처리 (numpy.fft)

푸리에 변환 : 신호 처리, 이미지 압축 등에 사용

주파수 영역으로 변환하여 분석 가능

```python
from numpy.fft import fft

signal = np.array([1, 2, 3, 4])
fft(signal)  # 푸리에 변환
```

### 🎲 난수 생성 (numpy.random)

정규분포, 균등분포 등 다양한 분포 기반 난수

```python
np.random.rand(3)  # 0~1 사이 난수 3개
np.random.normal(0, 1, 5)  # 평균 0, 표준편차 1인 정규분포 난수 5개
```

### 🆎 문자열 처리

넘파이의 `np.char` 모듈을 사용하면 문자열도 배열처럼 고속 처리 가능

```python
np.char.upper(['hello', 'world'])  # ['HELLO', 'WORLD']
```

## 🧭 넘파이 배열의 구조 : ndarray의 메타데이터
넘파이 배열(ndarray)은 단순한 데이터 저장소가 아니라 배열의 형태/타입/메모리 배치 방식 등을 설명하는 정보를 포함하고 있음 
### 넘파이 배열에 담긴 정보

| 속성 | 설명 | 예시 |
| --- | --- | --- |
| `dtype` | 배열에 저장된 **데이터 타입**. 모든 요소는 동일한 타입이어야 함. | `int32`, `float64`, `bool`, `str` 등 |
| `shape` | 배열의 **크기와 차원 구조**를 튜플로 표현. 각 차원의 길이를 나타냄. | `(3,)`: 1차원 벡터 `(2, 3)`: 2차원 행렬 (2행 3열) |
| `ndim` | 배열의 **차원 수**. 1차원, 2차원, 3차원 등. | `1`: 벡터`2`: 행렬`3`: 텐서 |
| `strides` | 메모리에서 다음 요소로 이동하기 위한 **바이트 단위 간격**. 배열의 **배치 방식**을 결정함. | `(24, 8)`: 행 기준으로 24바이트, 열 기준으로 8바이트 이동 |

### 축(axis)의 개념

넘파이에서는 배열의 각 차원을 **축(axis)**이라고 함

축은 데이터를 어떻게 나누고, 접근할지를 결정하는 기준

| 차원 | 축 설명 |
| --- | --- |
| 2차원 | `axis=0`: 행 방향 (세로)  `axis=1`: 열 방향 (가로) |
| 3차원 | `axis=0`: 면 (depth)  `axis=1`: 행  `axis=2`: 열 |

예를 들어, `np.sum(arr, axis=0)`은 **행 방향으로 합산**해서 열별 합계를 구함

### 파이썬 기본 자료구조와 넘파이 비교

넘파이를 이해하기 위해 파이썬의 기본 자료구조 복습

| 자료구조 | 특징 | 넘파이와의 관계 |
| --- | --- | --- |
| `list` | 동질적/이질적 데이터 모두 가능 | 넘파이 배열 생성에 자주 사용됨 |
| `tuple` | 불변형, 순서 있음 | 넘파이에서 shape 등으로 사용됨 |
| `dict` | 키-값 쌍 | 넘파이에는 직접 사용되지 않지만, 데이터 매핑에 활용 |
| `set` | 중복 없는 집합 | 넘파이에서는 잘 사용되지 않음 |

### ⚠️ 리스트 vs 넘파이 배열

- **리스트**는 다양한 타입의 데이터를 담을 수 있음
    예: `[1, "hello", 3.14]`
    
- **넘파이 배열(ndarray)**은 **동질적 데이터**만 저장 가능
    예: `np.array([1, 2, 3])` → 모두 정수형
    

> 리스트는 주소값을 통해 다양한 객체를 참조하지만,
>
> 넘파이는 **직접 데이터를 연속된 메모리 공간에 저장**해서 속도가 훨씬 빠름
