## 파이썬의 기본 원리- 기초 쌓기

- 파이썬을 배우기에 앞서 프로그래밍 언어들의 기본 지식에 대해 알아보기.
- 프로그래밍을 하려면 필요한 언어들이 존재!
> assembly(어셈블리) → C → C++ → java → 파이썬
>
> C는 고급 언어에 해당함.
- 내가 짠 코드를 컴퓨터가 읽게 하려면 기계어로 변환하는 작업이 필요
- 이 작업을 **컴파일**이라고 부름
- 기계어는 2진수로 되어 있고, 8비트의 자리를 이용해서 읽어들임.
  - 1바이트 = 8비트 ex) 00000001, 00000011
  - 1바이트 = 2의 8제곱. 즉, 256개의 데이터 표현이 가능

- C언어는 main이라는 진입 함수가 존재
  - 함수를 이용해서 프로그램을 짠다는 걸 알 수 있음.
  - 함수는 명령어들의 묶음이고, 추상화 작업을 진행한 것.
  - C는 많은 명령어들이 존재하지만 함수명이 1개이므로 함수명만 알고 있다면, 
  프로그램을 짤 수 있도록 했음. 
  - 데이터를 처리하려면 함수에 데이터를 전달해야 함. 이때 전역변수 처리가 필요
  - 그러나 어떤 함수에서 전역변수를 처리해야 하는지 모르는 상황이 발생

- C++ 등장.
  - C++에서는 함수와 데이터를 하나로 만드는 추상화를 진행 > 클래스라고 부름.
  - 클래스에는 **멤버변수, 멤버함수**가 들어가 있음.
  - 동적 메모리 할당 : why? 우리가 사용하는 데이터는 엄청 거대하기 때문에.

- 대량 데이터 처리
  - 메모리를 Heap과 Stack 영역으로 나눠 사용
- Heap 과 Stack  
  - 메모리가 부족하지 않도록 함수가 실행될 때, 필요한 데이터만 **stack**영역에 올려서 사용하게 됨.
  - 프로그램의 시작은 함수! > 함수가 함수를 호출하는 방향으로 프로그램을 구성
  - 호출을 한 후, 이 함수를 호출했던 원래 위치로 돌아가야 돼 

  → Stack이 늘어났다가 줄어드는 원리로 동작

  → ex) c언어에서 main 함수 안에 print(), read() 등의 함수를 실행하도록 작성

- 메모리 공간을 분리함으로써 적은 메모리 공간으로도 대규모 데이터 다루기 가능.
- 데이터는 주로 외부에 존재하고 있음.
- 많은 데이터를 처리하기 위해서 Heap영역에 메모리 일부만 옮김

**Heap** 

- 동적 메모리 할당 영역, 외부 데이터 일부만 읽어옴. 

- 함수가 처리될 때, Stack 영역에 데이터를 전달해야 하는데, 대량의 데이터가 stack 영역에 들어가면 overflow 발생 가능.
따라서 데이터가 어디에 있는지 위치만 알려줌
- Heap에다가 데이터를 로딩 해 놓고,
함수가 필요로 하는 데이터는 **Heap보다 작은 영역인 Stack에서** 함수가 동작할 때 **주소**만 넘겨 받게 됨.

### c언어에서 주소를 알고 싶을 때: 변수 앞에 포인터(*)를 사용함.
- *sample :  포인터 변수 sample을 뜻함.
- c언어에서 변수는 2가지가 존재함
  - 1 직접 데이터가 들어있는 변수 = **일반 변수**
  - 2 데이터를 동적 메모리에 할당해 놓고, 주소를 알려주는 변수 = **포인터 변수**

### 번외

- 자바에는 가비지 컬랙션 (- 시스템이 동적메모리 할당된 데이터 메모리를 해제 시키도록 해주는 것)이 있음. 

- 반면 C는 메모리 종료를 깜빡하고, 하지 않아 에러가 발생한 경우도 많음

- **python**은 순수한 객체지향 프로그래밍

  - 변수가 전부 주소로 저장. 따라서 초기화를 하지 않으면 에러 발생
  - 파이썬에서 변수는 모두 주소만 들어있는 포인터 형식
  - 데이터를 찾고 싶으면 주소를 타고 들어가서 데이터를 찾아야 함
  - 변수가 데이터의 주소라서 다른 언어들처럼 데이터 타입을 앞에 작성하지 않아도 되는 것
  - 초기화로 변수를 선언하지 않으면 에러가 발생
