# 2. 데이터 처리하는 방법

프로그램은 데이터를 처리하는 것!

Data의 종류

문자, 숫자, 이미지, 동영상, 사운드 등등 존재

모든 데이터를 처리하려면 일단 메모리에 로딩이 되어야 함.

데이터는 모두 2진수로 바꿔줘야 함. → 인코딩 이라고 부름

**숫자** - 2진수로 만들려면… 2로 나누는 것

**문자** - 코드표가 존재, 숫자로 변환하기 위해서- ASCII(아스키코드 사용- 65=A, 97=a)

**이미지** - 사이즈에 따라 격자를 만들고, 픽셀(pixel) 단위로 나눠준 뒤, 1픽셀의 rgb 값과 매핑 후 데이터 처리

rgb는 각각 256으로 이뤄져 있고 → 이 숫자를 기반으로 이미지를 만들 수 있는 것

**동영상** - 동영상도 이미지와 마찬가지… 이미지 여러개를 겹친거 → 반복하여 처리하면 동영상 처리 가능

**사운드** - 음역대 높이에 따라서 숫자로 바꾼 후 매핑해서 처리(음성 처리 할 때 배울 예정)

⇒ 이렇게!!! 데이터를 처리하려면 모두 2진수로 변환되어 있어야 함.

그렇다면, 숫자 65랑 문자 A의 아스키코드랑 똑같은 2진수인데 구분을 어떻게 할까? 데이터 타입으로 구분!

C언어를 보면 int a = 12 이렇게 지정해 놓으면,

a라는 변수에 10을 집어넣을 건데 데이터 타입은 int라고 선언하게 됨.

그리고 a변수에는 주소가 들어있는데 주소는 1바이트마다 나눠져 있음

int는 4바이트

a는 주소의 시작 위치이고, 사이즈는 데이터 타입이 정해준다.

⇒ 앞 포스팅에서 보았 듯 컴퓨터가 알 수 있도록 주소 값으로 바꿔 주는 작업을 ‘컴파일 한다’ 라고 함.

이를 기반으로 만들어진 실행 파일의 확장자가 .exe 파일임.

이 과정들을 모두 인코딩이라고 함.

컴퓨터는 연산을 제일 잘하는 친구. 계산하는 애

이미지, 숫자, 문자, 동영상, 사운드 모두 이진수 연산의 대상임.

ex)

이미지에 10을 더해주면 이미지가 밝아지는것 - 픽셀값이 올라갔으니까
이미지에 10을 빼주면 이미지가 어두워지는것 - 픽셀이 어두워지니까

연산(+더하기, -빼기, *곱하기, /나누기)만 잘하면 AI정복도 가능함.

인코딩된걸 사람이 보려면 다시 디코딩 되어야 함.
